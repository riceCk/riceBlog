React的生命周期

挂载

当组件实例被创建并插入 DOM 中时，其生命周期调用顺序如下：

constructor()
static getDerivedStateFromProps()
render()
componentDidMount()

更新

当组件的 props 或 state 发生变化时会触发更新。组件更新的生命周期调用顺序如下：

static getDerivedStateFromProps()
shouldComponentUpdate()
render()
getSnapshotBeforeUpdate()
componentDidUpdate()

React-router v6 路由总结

组件

  • BrowserRouter: 整个前端路由以history模式开始，包裹根组件
  • HashRouter：整个前端路由以hash模式开始，包裹根组件
  • Routes：类似于v5版本的Switch，主要是提供了一个上下文环境
  • Route: 在Route组件中书写你对应的路由，以及路由所对应的组件
    • path： 匹配的路由
    • element：匹配上该路由时要渲染的组件
  • Navigate: 导航组件，类似于useNavigate的返回函数，不过这是一个组件
  • NavLink: 类型与Link，类似于Link，最终和Link一样，会被渲染为a标签，注意它和Link的区别，实际上就是当前链接，会有一个名为active的激活样式，所以一般用于做顶部或者左侧导航栏的跳转

Hooks

  • useLocation: 获取到loaction对象，获取到location对象后，我们可以获取到state属性，由上级页面路由跳转state里面携带的额外数据
  • useNavigate: 调用之后会返回一个函数，通过该函数可以做跳转
  • useParams: 获取动态参数
