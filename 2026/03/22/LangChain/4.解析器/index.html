3.解析器

发表于 2026-03-22 | 分类于 LangChain |

字符串解析器

默认情况下LangChain中调用的LLM返回的不是一个简单的字符串，而是一个包含大量元信息的对象。

解析器的作用

拿到模型的输出后，利用解析器可以帮助我们将LLM原始输出转行成结构化数据，常用语：

  • 提取JSON、列表、对象、代码块
  • 数据清洗与格式化
  • 配合TOOl / Agent 提取指令参数

列表输出解析器

有些场景，希望模型输出一个简单的字段串列表，比如：列出三个美国的互联网公司


这时候就需要CommaSeparatedListOut

补充一点数据流向决定 pipe 顺序
输入 → 模板 → 模型 → 解析 → 输出
谁先处理数据，谁就在最前面

JSON解析器

需要拿到一段合法的JSON格式输出，用到JsonOutputParser


和StringOutputParser的区别：

  • StringOutputParser：有明确的字段结构，告诉大模型、必须按照格式来
  • JsonOutputParser：只想提取JSON内容或做快速原型，只要输出JSON就行

{
“name”: “Taizhou”,
“country”: “China”,
“location”: {
“lat”: 32.415333,
“lng”: 119.735278
},
“population”: 5111300
}
