实战示例

  1. main：JVM 规定的程序入口，固定小写，是静态方法，不是构造方法，不负责 new 对象
  2. 构造方法：名字与类名相同，配合 new 创建并初始化对象
  3. Income[] incomes = new Income[]{ ... }：父类类型数组，可存放父类 + 所有子类实例
  4. 多态核心：父类引用指向子类对象，调用被 @Override 重写的方法时，执行子类实现
  5. Income... 可变参数，等价于 Income[]，数组可直接传入

调用 super 和 final

  • 子类覆写方法中，可通过 super 调用父类被覆写的方法
  • 父类不想让子类覆写某方法，可标记为 final
  • final 修饰的字段初始化后不可改，可在构造方法中赋值
