静态字段和静态方法

静态字段

无论通过哪个实例修改静态字段，所有实例看到的值都会变——因为静态字段不属于某个实例，而属于类本身。

静态方法

静态方法属于 class，不属于实例，因此内部无法访问 this，也无法访问实例字段，只能访问静态字段。

常用于工具类，例如：

  • Arrays.sort()
  • Math.random()

接口的静态字段

  1. 接口中的字段默认隐式自带 public static final，写不写修饰符都生效
  2. 可以只写一部分修饰符，编译器自动补齐
  3. 本质是静态常量：属于接口本身，不属于实现类实例，不可修改
  4. 禁止用 private、protected 修饰接口内字段
  5. 接口没有实例字段；抽象类可以有普通实例字段

包

包作用域

同一包（例如 ming）内，Main 可直接调用 Person 的方法；方法即使不写 public 也能被同包访问。其他包则禁止访问非 public 成员。

import

其他包要调用 ming 包中的类，有三种写法：

  1. 直接写出完整类名
  1. 用 import：可按类引入 import ming.Person，也可按包全量引入 import ming.*。通常不建议用 *，多包导入后很难分辨来源。
  1. import static：导入某个类的静态字段和静态方法

⚠️ 若两个 class 同名（如 mr.jun.Arrays 与 java.util.Arrays），只能 import 其中一个，另一个必须写完整类名。
