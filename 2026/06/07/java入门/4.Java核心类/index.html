包装类型

Java 数据类型分两种：

  • 基本类型： byte、short、int、long、boolean、float、double、char
  • 引用类型： 所有 class 和 interface

引用类型可赋 null；基本类型不行：

Integer 使用注意：

  1. == 比较的是对象地址，不是数值；比数值用 .equals()
  2. 缓存范围：-128 ~ 127，此区间内 valueOf 复用对象；超出则新建，不能靠 ==
  3. new Integer() 一定创建新对象，不与缓存相等
  4. 开发规范：不要用 new Integer，统一用 Integer.valueOf()
