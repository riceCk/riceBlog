📦 变量和数据类型

基本数据类型

基本数据类型是 CPU 可以直接运算的类型。Java 定义了以下几种：

  • 🔢 整数类型：byte(1b)，short(2b)，int(4b)，long(8b)
  • 📐 浮点数类型：float(4b)，double(8b)
  • 🔤 字符类型：char(2b)
  • ✅ 布尔类型：boolean

整型

Java 只定义了带符号整型，最高位 bit 表示符号位（0 正数，1 负数）。各类型取值范围如下：

  • byte：-128 ~ 127
  • short：-32768 ~ 32767
  • int：-2147483648 ~ 2147483647
  • long：-9223372036854775808 ~ 9223372036854775807

浮点型

浮点数就是小数。用科学计数法表示时，小数点可以「浮动」，例如 1234.5 可写成 12.345×10²，也可写成 1.2345×10³，因此叫浮点数。

🖨️ 输入输出

占位符 说明
%d 格式化输出整数
%x 格式化输出十六进制整数
%f 格式化输出浮点数
%e 格式化输出科学计数法浮点数
%s 格式化字符串

输入

💡 先通过 import java.util.Scanner 导入类（import 须放在源码开头）。读字符串用 scanner.nextLine()，读整数用 scanner.nextInt()。Scanner 会自动做类型转换，不必手动转。
