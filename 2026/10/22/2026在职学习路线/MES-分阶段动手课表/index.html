MES 分阶段动手课表

发表于 2026-10-22 | 分类于 在职学习路线 |

前端转 Java · MES 方向分阶段动手课表

配合 MES-在职学习路线清单.md 使用。你当前进度：阶段 1 已开始，廖雪峰看到 3.1.5 多态。
原则：每一步必须写代码；中文资料优先；不学分布式/高并发；不买万元课也能走完全程。

0. 先对照海报课：哪些拿来用，哪些扔掉

海报「AI 大全栈 / 10500」模块很多，不要按它的目录买课、也不要按它的顺序学。
下面是映射到你泰州 MES 目标后的取舍。

海报模块 对本路线 处理
JAVA ✅ 正在学 用廖雪峰（已剪裁），不另买课
Spring 全家桶 ✅ 精简版 只学 Spring Boot + Web + 事务，不学 Cloud
数据库和 ORM ✅ MySQL + MyBatis-Plus
Redis 👀 阶段 4 再碰登录态/字典缓存
MQ 消息队列 ⏭️ 工单 CRUD 用不到
微服务架构 🚫 单体会更贴本地岗
企业中间件 ⏭️
高并发 🚫 明确禁止
AI 编程工具 / Vibe Coding ✅ 当助手 用 Cursor / 通义等加速写代码，不能替代你自己写 CRUD
Spec / Agent Coding、代码审核、自动化测试 👀 后期有空再看，不挡主线
Transformer / Harness / Loop / LangGraph / DeepAgent ⏭️/🚫 科研向，本地 MES 岗不问
n8n 👀 可了解低代码编排，不作为技能主线
RAG / LangChain ✅ 附加 主项目闭环后再做 SOP 问答
Linux 👀 会 SSH、基础命令即可
Docker ✅ 后期 一键起 MySQL + 自己的 jar
K8s / DevOps / 安全审计 / 监控全家桶 🚫
海报里的「智能客服 / 内容审核」项目 🚫 行业不对；你的项目必须是 工单/报工 MES

结论： 海报里真正对你有用的是「Java + Spring Boot + 库表 + AI 当助手 + 后期 RAG + Docker」。其余当广告。

1. 总课表（接在现有清单上）

每周仍按 10～12 小时。阶段 1 未验收，不要跳去 Spring 后面。

代号 名称 预估 你必须交出来的东西
S0 MES 业务入门 2～3 周（可与 S1 前半并行） 词汇表 + 主流程图
S1A Java 语法够用（你正在这） 2～2.5 周 内存版「车间/物料」小练习
S1B Maven + IDEA 工程 3～5 天 能 mvn package 的空壳
S1C Spring Boot + MySQL + MP 2.5～3 周 车间 CRUD 接口
S1D 登录权限 + 接口文档 1～1.5 周 带登录的 mes-basic-api
S2 工单业务后端 5～6 周 最小 MES：工单 CRUD + 状态 + 报工
S3 Vue 联调 5～6 周 页面能走通主流程
S4 打磨部署 4～5 周 README + 演示脚本
S5 面试 3～4 周（可重叠） 题库 + 开始投递
S6 可选 AI 加分 1～2 周 SOP 文档问答挂到 MES 上

下面每个阶段都按固定六块写：学习目标｜核心知识点（含取舍）｜实操任务｜中文资源｜预估时间｜避坑。

S0 · MES 业务入门

学习目标

能用车间的人听得懂的话，讲清：MES 管什么、不管什么；一张工单从下达到完工怎么走。

核心知识点

  • ✅ 对象：车间、产线、设备、物料、工艺路线、工序、工单、报工、质检、WIP
  • ✅ 主流程：计划下发 → 开工单 → 领料 → 开工 → 报工 → 质检 → 入库
  • 👀 ERP / WMS / QMS 边界；离散 vs 流程
  • ⏭️ ISA-95 全文、PLC/OPC、APS 算法、精益生产专著

实操任务（必须动手，不是只看视频）

  1. 用纸或 diagrams.net 画一张 工单主流程图（方框+箭头，标角色）。
  2. 建一个笔记页，自己写 40 个词 的解释（工单、报工、不良、超报、下达、关闭……），禁止复制粘贴百科。
  3. 用自己的话录音 5 分钟：MES 和 ERP 有什么区别。听一遍，卡壳的词补进词汇表。

中文学习资源

  • B 站搜索：MES系统讲解 工单 报工（选有界面演示的，看 2～3 个即可，不要连播 20 集）
  • 科普检索：制造执行系统 MES 功能模块、生产工单 报工 质检
  • 厂商介绍页只看「模块图」（用友/鼎捷/宝信等公开介绍），当词典，不当教材

预估时间

2～3 周，每周 8～10 小时。可与 S1A 晚上学语法、周末补业务并行。

避坑提醒

  • 看懂界面 ≠ 懂业务。以你能讲、能画为准。
  • 不要收集一堆「工业互联网」PPT。

S1A · Java 语法够用（当前阶段）

学习目标

看懂并手写：类、继承、多态、接口、异常、List/Map、时间、简单 Lambda。
不是学完廖雪峰全书。

核心知识点（对接廖雪峰目录）

✅ 精读并敲代码

  • 3.1.6 抽象类、3.1.7 接口、3.1.8 静态、3.1.9 包
  • 3.2.1 字符串、3.2.4 包装类型、3.2.5 JavaBean、3.2.6 枚举、3.2.9 BigDecimal
  • 4.1～4.5 异常与 NPE；4.10 SLF4J/Logback（可稍后和 Spring 一起）
  • 7.1～7.2 泛型使用
  • 8.1～8.2 List、8.4 Map、8.9 Set
  • 10.3 LocalDateTime、10.5 DateTimeFormatter、10.7 最佳实践
  • 19.1～19.2 Lambda；19.3 Stream 的 map/filter/toList

👀 浏览

  • 3.1.10 作用域、3.1.11 内部类、3.1.12 jar
  • 3.2.2 StringBuilder、3.2.7 record
  • 8.3 equals、8.5 hashCode、8.14～8.15
  • 6.1 使用注解

⏭️ 直接跳过（不要深挖）

  • 3.1.13～3.1.14、3.2.8 BigInteger
  • 第 5 章反射、7.4～7.7、8.10～8.13 队列栈
  • 第 9 章大部分 IO、第 13～14、16、20、21、24 整章
  • 多线程、网络、设计模式全书、Spring Cloud

详细对照表见 MES-在职学习路线清单.md 附录。

实操任务（每学完一小块必须写）

用 制造名词 练习，不要再用 Animal/Dog。

  1. 多态/接口作业（本周就做）
  • 写接口 Device：方法 start()、stop()、getStatus()
  • 实现类 CncMachine、AssemblyLine
  • main 里用 List<Device> 装两种设备，循环调用（体会多态）
  1. 枚举作业
  • WorkOrderStatus：待下达、已下达、生产中、暂停、完工、关闭
  • 写方法：哪些状态允许报工、哪些允许关闭
  1. 集合作业（内存版迷你 MES）
  • Workshop、Material 两个 JavaBean
  • 用 HashMap<String, Material> 按物料编码增删改查
  • 用 ArrayList<Workshop> 按名称过滤
  1. 数量作业
  • 用 BigDecimal 算：计划 100，已报工 96，本次报工 5 → 应拦截超报
  • 禁止用 double 做数量
  1. 时间作业
  • 工单 planStart/planEnd 用 LocalDateTime，格式化成 yyyy-MM-dd HH:mm

中文学习资源

  • 主教材：廖雪峰 Java 教程（按上表剪裁，不要目录通读）
  • 卡壳时查：菜鸟教程 Java 对应单页
  • 集合直观理解：B 站搜 Java ArrayList HashMap 通俗（看 1 个短系列即可）

预估时间

从多态起再 2～2.5 周（每周 10 小时）。做完上面 5 个练习再进 S1B。

避坑提醒

  • 看完一节马上写练习，不要攒着「周末一起敲」。
  • 接口这一节是重中之重：后面 XxxService 全是接口+实现。
  • 不要因为教程后面还有「反射/多线程」而焦虑，那些是刻意跳过的。

S1B · Maven + IDEA 工程化

学习目标

能新建 Maven 项目、加依赖、编译打包，理解 src/main/java 和包名。

核心知识点

  • ✅ Maven：坐标、依赖、mvn compile/package
  • ✅ IDEA：JDK 17（或 11）、项目结构、运行 main
  • 👀 mvnw、多模块
  • ⏭️ 发布到私服、复杂插件

实操任务

  1. 安装 JDK 17 + IntelliJ IDEA Community。
  2. 新建 Maven 项目 mes-basic-api，包名例如 com.taizhou.mes。
  3. 写一个 HelloMes 打印 MES basic api，命令行 mvn -q exec 或 IDEA 运行成功。
  4. 把 S1A 的 Device/WorkOrderStatus 搬进这个项目，保证能编译。

中文学习资源

  • 廖雪峰 · Maven 基础（15.1～15.3 ✅，后面 👀）
  • IDEA 中文入门：B 站搜 IDEA 2024 入门 创建 Maven

预估时间

3～5 天（可塞进一个周末 + 两个晚上）。

避坑提醒

  • JDK 版本和语言级别不一致会导致一堆红字，先统一 17。
  • 先别上 Spring，确认普通 Java 项目能跑。

S1C · Spring Boot + MySQL + MyBatis-Plus（阶段 1 核心）

学习目标

独立从零起一个 Boot 项目：连上 MySQL，给「车间」做增删改查+分页，用 Apifox/Knife4j 点通。

核心知识点

  • ✅ Spring Boot 启动、application.yml、分层 Controller / Service / Mapper / Entity
  • ✅ 统一返回体 {code, msg, data}、全局异常、@Valid 校验
  • ✅ MySQL：建库建表、主键、索引直觉（按车间编码、状态查）
  • ✅ 事务概念（先知道 @Transactional 用在「改两张表」时）
  • ✅ MyBatis-Plus：BaseMapper、条件构造器、分页
  • 👀 Lombok、逻辑删除、自动填充
  • ⏭️ Hibernate/JPA 深度、手写复杂 XML、连接池调优、读写分离

实操任务（按天做，不要只看视频）

第 1 天：空项目跑起来

  1. Spring Initializr 选 Maven、Java 17、Spring Web、Validation（或纯手写 pom）。
  2. 写一个 GET /api/health 返回 ok。浏览器能打开。

第 2～3 天：数据库

  1. 本地安装 MySQL 8，建库 mes_demo。
  2. 建表 workshop：id, code, name, status, remark, created_at。
  3. 手工 INSERT 3 条车间数据。

第 4～6 天：CRUD 写完

  1. Entity Workshop、Mapper、Service、Controller。
  2. 接口必须有：新增、按 id 查、分页列表（支持名称模糊）、修改、删除。
  3. 用 Apifox 把 5 个接口各打一遍，截图或导出记录留着。

第 7 天：统一返回 + 校验

  1. 车间编码不能空、不能重复；删除不存在的 id 要返回明确错误，而不是 500。

中文学习资源

  • Spring Boot 入门（中文社区整理）：Spring Boot 中文索引 ；官方参考可开翻译：文档里先跟「第一个应用」走
  • 更顺的中文路径：廖雪峰 · Spring Boot 第一个应用（23.1～23.3 ✅）
  • ORM：MyBatis-Plus 中文 · 快速开始
  • 分页：MyBatis-Plus 分页插件（做到列表再看）
  • B 站搜：Spring Boot 3 MyBatis-Plus CRUD（选 单体后台，标题带「秒杀/微服务/高并发」的直接划掉）
  • SQL：菜鸟教程 MySQL 建表/增删改查/索引入门几页

预估时间

2.5～3 周。

避坑提醒

  • Spring Boot 3 必须 JDK 17，和 MP 要用 mybatis-plus-spring-boot3-starter。
  • 不要同时引入 MyBatis 官方 starter 和 MP starter。
  • 接口路径用 /api/workshops 这种 REST，别写成 doAdd.action。
  • 数量、金额字段以后一律 decimal，不要 float。

S1D · 登录、RBAC、接口文档

学习目标

做出可演示的 mes-basic-api：登录拿 token，不同角色看到不同权限；文档页能调试。

核心知识点

  • ✅ JWT 或 Session 二选一（建议 JWT，前后端分离方便）
  • ✅ 用户-角色-菜单（先做用户-角色，菜单可先写死配置）
  • ✅ 拦截器/过滤器：除登录外校验 token
  • ✅ Knife4j 打开 doc.html
  • 👀 Redis 存 token（先内存/数据库也行）
  • ⏭️ Spring Security 全家桶、OAuth2、网关鉴权

实操任务

  1. 表：sys_user、sys_role、sys_user_role。预置 admin / operator。
  2. POST /api/auth/login 返回 token；错误密码返回 明确业务码。
  3. 车间写接口：admin 可删，operator 只能查、不能删（先在代码里判断角色即可）。
  4. 接入 Knife4j，给接口写中文注释，用文档页把登录+CRUD 走通。
  5. 阶段 1 总验收： 换一台电脑或清 Maven 缓存后，按 README 能启动并演示。

中文学习资源

  • Knife4j 中文 · 快速开始
  • JWT 原理+落地：B 站搜 Spring Boot JWT 登录 拦截器（避开 Security 复杂课；先拦截器版）
  • 统一异常：搜 Spring Boot 全局异常处理 ControllerAdvice

预估时间

1～1.5 周。

避坑提醒

  • 别一上来上完整 Spring Security，容易学一周还没登录页。拦截器足够支撑 Demo 和面试讲解。
  • 密码至少 BCrypt 哈希，不要明文。中文说明见 Spring 文档或搜 BCryptPasswordEncoder 示例。

S2 · 最小 MES 后端（工单 CRUD 是硬指标）

学习目标

在 mes-basic-api 上扩展成 最小 MES 后端 Demo：工单全生命周期 + 简单报工，能用接口演示，不需要前端也能讲清业务。

核心知识点

  • ✅ 表设计：物料、工单、工单状态、报工记录
  • ✅ 状态机：待下达 → 已下达 → 生产中 → 完工 / 关闭（暂停可选）
  • ✅ 报工：合格数、不良数；超报拦截；更新工单完成数量必须 同一事务
  • ✅ 列表筛选：工单号、状态、日期
  • ✅ Excel 导出工单列表（加分，尽量做）
  • 👀 质检单、领料、设备台账（本阶段能做质检更好，做不完放到 S3）
  • ⏭️ APS 排程、复杂 BOM 多层、设备采集、微服务拆分

实操任务（按模块提交）

模块 A · 物料主数据（2～3 晚）

  • 表 material(code, name, spec, unit)
  • CRUD 接口，编码唯一

模块 B · 工单 CRUD（1.5 周）

  • 表 work_order：工单号、物料、计划数量、完成数量、状态、计划时间、车间 id
  • 接口：创建（默认待下达）、修改（仅待下达可改）、分页查询、详情
  • 动作接口：下达、开工、完工、关闭（非法状态流转必须报业务错误）

模块 C · 报工（1.5 周）

  • 表 report_record：工单 id、合格数、不良数、报工人、时间
  • POST /api/work-orders/{id}/reports
    1. 校验状态允许报工
    2. 合格+不良+已完成 ≤ 计划数，否则拒绝
    3. 插入报工行 + 更新工单完成数，加 @Transactional
    4. 完成数达到计划数时，可自动变完工或提示去点完工（你选一种写进 README）

模块 D · 自测脚本

  • 用 Apifox 收藏一套请求：建物料 → 建工单 → 下达 → 开工 → 报工两次 → 超报失败 → 完工
  • 故意不写事务对比一次（本地实验后改回来），自己能讲「没事务会怎样」

中文学习资源

  • 事务：廖雪峰 · JDBC 事务 建立概念；实际用 Spring @Transactional
  • 状态流转自己画图，比任何课都重要
  • EasyExcel 中文：搜 EasyExcel 快速开始 阿里（导出工单）
  • B 站可搜 工单 状态机 理解思想，不要去找互联网「订单中台」课

预估时间

5～6 周。

避坑提醒

  • 工单号、状态、四个数量（计划/完成/合格/不良） 是业务核心，比框架花活重要。
  • 不要并行开发质检+库存+设备+看板。工单+报工不通，后面全是空中楼阁。
  • 数量用 decimal/BigDecimal。

S3 · Vue3 联调（发挥你的前端优势）

学习目标

车间管理员能在浏览器里完成：登录 → 建物料 → 开工单 → 报工 → 看列表状态。这是你简历主项目的「可见部分」。

核心知识点

  • ✅ Vue3 + Vite + Element Plus（或你已熟的 AntD Vue）
  • ✅ Axios 封装、token 放到 Header、401 跳登录
  • ✅ 工单列表/详情、状态按钮、报工弹窗
  • ✅ 按钮级权限（删除/关闭按角色隐藏）
  • 👀 ECharts 工单数量柱状图
  • ⏭️ 微前端、Nuxt、原生 APP

实操任务

  1. 新建 mes-web，登录页对接 S1D。
  2. 车间、物料两个管理页（你最熟的 CRUD 页面，先热手）。
  3. 工单页：表格 + 状态下拉 + 「下达/开工/报工/完工」按钮。
  4. 报工弹窗：填合格/不良，超报时展示后端返回的中文错误。
  5. （可选）一个简单首页：今日工单数、生产中数量。

中文学习资源

  • Vue3 中文文档
  • Element Plus 中文文档
  • ECharts 中文手册
  • Vite：中文指南

预估时间

5～6 周。

避坑提醒

  • 不要重写一套前端框架。你的差异化在 业务闭环，不在换技术栈。
  • 错误信息必须是中文业务句（「报工数量超过剩余可报数量」），方便面试演示。

S4 · 打磨、部署、简历

学习目标

别人按 README 能跑起来；你能 8 分钟演示主流程；简历有一条像样的制造业项目。

核心知识点

  • ✅ README：环境、账号、演示路径、表结构截图/ER 图
  • ✅ 简单部署：单机 java -jar + Nginx 托管前端，或 Docker Compose 起 MySQL
  • 👀 操作日志、防重复提交
  • ⏭️ K8s、CI 全家桶、监控告警平台

实操任务

  1. 补 ER 图（车间、物料、工单、报工、用户角色）。
  2. 写 README（安装 JDK/MySQL、导入 SQL、启动命令、演示账号）。
  3. 自己按 README 在「干净环境」走一遍。
  4. 录 8 分钟演示（或写逐步截图脚本）。
  5. 按路线清单第 6 节话术改简历项目描述。
  6. （建议）docker-compose.yml：只含 MySQL，后端仍可本地跑。

中文学习资源

  • Docker 入门中文：搜 Docker Compose 中文 入门 MySQL（官方中文：Docker 文档中文社区 或华为云/腾讯云翻译的 Compose 入门）
  • Nginx 静态部署：菜鸟教程 Nginx + 搜 Vue Vite 打包 nginx

预估时间

4～5 周（含修 bug）。

避坑提醒

  • 简历不要写 Kafka、微服务、千万并发。面试官按你写的追问。
  • Demo 是 Demo，面试别吹成某车企真实 MES。

S5 · 面试冲刺（可与 S4 后两周重叠）

学习目标

业务题能答、项目能画表、开始投泰州制造信息化/MES 岗。

核心知识点

  • ✅ 工单状态、超报、事务、权限、MES vs ERP
  • ✅ 你的表为什么这么拆
  • 👀 索引怎么建、慢 SQL 怎么看 explain
  • ⏭️ 算法刷题大战、JVM 调优、分布式事务

实操任务

  1. 准备 20 道自问自答（业务 10 + 项目技术 10），写在笔记里 大声说出来。
  2. 对着 ER 图，不看代码讲一遍报工接口。
  3. 列出 ≥15 家目标：药企信息化、工厂数字化、本地 MES 实施的研发岗。
  4. 同步保留一条「资深 Vue」保底简历。

中文学习资源

  • 用你自己的 Demo 当唯一教材
  • SQL：菜鸟教程 EXPLAIN、索引几页
  • 路线清单第 6 节高频题

预估时间

3～4 周。

避坑提醒

  • 先投岗位再追求完美功能。本地窗口窄，空窗贵。

S6 · 可选加分：MES 上的 SOP 问答（对应海报 RAG，但缩水）

前置：S2 工单闭环已完成。 否则禁止开始。

学习目标

上传一份作业指导书 PDF/Markdown，按问题返回带引用的答案。证明「AI 接到现有 MES」，不是会玩聊天机器人。

核心知识点

  • ✅ 文档切分、向量检索、提问、引用原文
  • 👀 LangChain 中文入门概念
  • ⏭️ 微调、Transformer 原理、LangGraph、多智能体、私有化大模型训练

实操任务

  1. 写 3 篇假 SOP（设备开机、报工规范、不良处理）。
  2. 做一个 /api/ai/ask：入参问题，出参答案+来源段落。
  3. 前端工单页加「规范问答」抽屉即可。

中文学习资源

  • 搜 RAG 检索增强 原理 通俗、Spring Boot 调用 通义千问 API
  • LangChain 有中文社区文档，只看 RAG 最小例子
  • 模型 API 用国内：通义/智谱/DeepSeek 开放平台中文文档（注意费用，控制在几块钱试跑）

预估时间

1～2 周。

避坑提醒

  • 简历占比不超过 15%。
  • 不要写「精通大模型」。写「为 MES 增加 SOP 检索问答」。

2. 每周节奏（打工人版）

时段 做什么

周六 3～4h 本周实操任务收口
周日 2h 复习错点 + 更新自检清单打勾
加班周 降到 6h，只复习不贪新章

AI 编程工具怎么用（对应海报「高效 AI 编程」）：

  • ✅ 允许：解释报错、生成样板 getter、问「MyBatis-Plus 分页怎么写」
  • ✅ 允许：让它根据你的表结构生成首版 Entity，你必须读改
  • ⏭️ 禁止：整页 Controller 让 AI 写完你却讲不清
  • 验收标准：关掉 AI，你能从零写出报工接口的关键 30 行

3. 学习自检清单（每学完一块就勾）

S0 业务

  • 5 分钟讲清 MES vs ERP
  • 画出主流程并标角色
  • 词汇表 ≥ 40 词，都是自己的话
  • 能解释：下达、报工、超报、WIP、工艺路线

S1A Java 语法

  • 接口+两个实现类，用父类型集合调用
  • 工单状态枚举 + 允许报工的判断方法
  • HashMap 内存增删改查物料
  • BigDecimal 超报计算写对
  • LocalDateTime 格式化输出
  • 廖雪峰反射/多线程/Cloud 没有当成当前任务

S1B 工程

  • IDEA 运行 Maven 项目无红字
  • 知道 pom.xml 里依赖坐标是什么意思

S1C Spring + 库

  • /api/health 通
  • 车间 5 个接口 Apifox 全绿
  • 编码重复、参数空有中文错误
  • 分页按名称过滤可用
  • 能自己讲：请求怎么到 Controller 再到数据库

S1D 权限文档

  • 登录拿 token，无 token 访问车间失败
  • admin / operator 权限有差异
  • Knife4j 能调试
  • 密码非明文

S2 最小 MES

  • 物料 CRUD
  • 工单创建/查询/修改
  • 下达、开工、完工、关闭；非法流转被拒绝
  • 报工写入记录并更新完成数
  • 超报失败
  • @Transactional 用在报工上，能口述没事务的后果
  • Apifox 一套主流程收藏能重放

S3 前端

  • 登录进系统
  • 页面完成建工单→报工
  • 超报错误展示给用户
  • 角色按钮差异可见

S4 打磨

  • README 陌生人 30 分钟能启动
  • ER 图能手画
  • 8 分钟演示稿
  • 简历项目描述无微服务/高并发词汇

S5 面试

  • 20 题能口头答
  • 目标公司清单 ≥ 15
  • 保底前端简历已准备

S6 可选

  • 问答接口能引用 SOP 原文
  • 挂在 MES 页面上，而不是独立玩具
