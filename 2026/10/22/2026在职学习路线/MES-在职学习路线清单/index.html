MES 在职学习路线清单

发表于 2026-10-22 | 分类于 在职学习路线 |

前端转 Java 全栈 · 泰州制造业 MES 方向（在职学习路线）

适用：多年 Vue 政企后台经验 · 在职不裸辞 · 目标泰州本地 MES/制造信息化全栈 · 薪资底线 12k · 尽量双休
原则：围绕工单、设备、物料、质检、报工；不学一线互联网高并发/分布式套路
每天动手写什么、中文资料链接、自检打勾：见同目录 MES-分阶段动手课表.md

1. 整体规划

总周期建议：约 7～9 个月（在职）

阶段 名称 时长 每周投入 阶段目标
0 MES 业务入门 + 技术栈定锚 2～3 周 8～10 小时 能讲清 MES 干什么，知道自己要做成什么系统
1 Java 后端地基（Spring Boot） 6～7 周 10～12 小时 独立写业务 API、连库、做权限与基础 CRUD
2 制造业务数据与核心模块 5～6 周 10～12 小时 完成工单/物料/报工等核心表设计与接口
3 Vue + Java 全栈联调 5～6 周 10～12 小时 做出可演示的 MES 后台（前后端一体）
4 完整 Demo 打磨 + 简历包装 4～5 周 8～12 小时 形成可面试讲解的制造业信息化项目
5 面试冲刺（可与第 4 阶段重叠 2 周） 3～4 周 6～10 小时 覆盖本地 MES 高频题，开始投递

每周节奏建议（打工人版）

  • 工作日：每天 1～1.5 小时（编码/看文档）
  • 周末：一天 3～4 小时做项目，另一天复习+写笔记
  • 合计：约 10～12 小时/周；加班周可降到 6～8 小时，把周期拉长，别硬冲

总原则

  1. 每个阶段有「必须做完的小项目」，没验收不进入下一阶段
  2. 业务名词优先于框架名词
  3. 简历叙事始终是「制造业信息化全栈」，不是「Java 培训转型生」

2. 分阶段学习清单

阶段 0：MES 业务入门（2～3 周）

必须掌握

  • MES 是什么：连接计划（ERP）与现场执行的生产执行系统
  • 核心对象：工厂/车间/产线、设备、物料、BOM、工艺路线、生产工单、工序、报工、质检、库存/在制品（WIP）
  • 一条主流程能讲清楚：
    计划下发 → 工单创建 → 领料 → 工序开工 → 报工 → 质检 → 入库/流转
  • 常见角色：计划员、车间主任、操作工、质检员、设备员
  • 你目标岗位日常在干什么：改页面、写接口、查 SQL、跟现场对需求、改报表、修数据

了解即可

  • ISA-95、MOM、APS、SCADA、PLC 是什么层级关系
  • 离散制造 vs 流程制造差异（泰州常见：机械装备、电子、医药固体制剂等）
  • WMS / QMS / ERP 和 MES 怎么边界划分

可以跳过

  • 精益生产理论全书
  • 工业协议深挖（OPC UA 底层、PLC 编程）——除非 JD 明确要求
  • 数字孪生、工业互联网平台概念文

阶段产出

  • 一页「MES 业务词汇表」（自己写，30～50 个词）
  • 一张手绘/Draw.io 主流程图

阶段 1：Java 后端地基（6～7 周）

你已有前端经验，别从零刷语法百科，按「能写业务接口」学。

必须掌握

  • Java 基础够用集：面向对象、集合、异常、泛型、常用 IO/时间 API、Lambda
  • Maven/Gradle 会一种即可（推荐 Maven）
  • Spring Boot 2.x/3.x：启动、配置、分层（Controller/Service/Mapper）
  • 统一返回体、全局异常、参数校验（Validation）
  • MyBatis-Plus 或 MyBatis：CRUD、条件查询、分页
  • MySQL：表设计、主键、索引基础、事务（ACID、脏读/幻读知道概念即可）
  • 登录鉴权：JWT 或 Session 选一种；RBAC（用户-角色-菜单/按钮）
  • 接口文档：Knife4j / SpringDoc 会一种
  • 本地运行：IDEA + MySQL + Postman/Apifox

了解即可

  • Redis 做登录态/字典缓存（会 get/set/expire 就行）
  • Docker 一键起 MySQL（方便换电脑）
  • 文件上传（质检附件、工艺文件）

可以跳过

  • JVM 调优、GC 细节
  • 高并发、秒杀、分布式锁、MQ 集群、微服务拆分、K8s
  • Netty、响应式 WebFlux
  • 复杂设计模式背诵（会 Service 分层、策略模式偶尔用即可）

阶段产出

  • 项目：mes-basic-api
    功能：用户登录、角色权限、字典管理、部门/车间基础数据 CRUD

阶段 2：制造业务数据与核心模块（5～6 周）

这是拉开差距的阶段：表设计 = 业务理解。

必须掌握

  • 主数据：物料、设备、车间/产线、工艺路线、工序、BOM（先做单层 BOM）
  • 业务单据：生产工单、工单工序、领料单、报工单、质检单
  • 状态机思维：工单状态（待下达/已下达/生产中/暂停/完工/关闭）
  • 报工逻辑：合格数、不良数、工时；防止超报（简单校验即可）
  • 基础库存/WIP：入库、扣料（先做简化台账，不做复杂仓储算法）
  • 多表事务：报工时同时写报工记录 + 更新工单完成量
  • 列表筛选：按车间、状态、日期、工单号查询
  • 导出 Excel（工单/报工报表）——制造业很吃香

了解即可

  • 批次/序列号管理
  • 简单不良代码、质检抽样（AQL 知道概念即可）
  • 设备点检/保养台账（一张表+提醒字段）

可以跳过

  • 高级排程 APS、有限产能排产算法
  • 复杂 MRP 运算
  • 立体库、波次拣选等纯 WMS 深度

阶段产出

  • 项目：mes-core-api（可在阶段 1 项目上迭代）
    模块：物料、设备、工艺路线、生产工单、报工、质检（先 API + 表结构 + Swagger 可测）

阶段 3：Vue + Java 全栈联调（5～6 周）

发挥你的前端优势，把系统做成「能给面试官点开看」的东西。

必须掌握

  • Vue3 + Vite + Element Plus / Ant Design Vue（你熟哪个用哪个）
  • 动态路由与按钮级权限（对接后端 RBAC）
  • 工单列表/详情、报工弹窗、质检录入、设备台账页
  • 前后端联调：环境变量、代理、统一请求封装、错误码处理
  • 表单校验、状态标签、操作日志展示
  • 简单大屏/看板二选一：今日工单进度、产线报工统计（ECharts）

了解即可

  • 打印工单流转卡（浏览器打印 CSS）
  • WebSocket 推送报工刷新（没有也可）
  • 移动端 H5 报工页（加分，非必须）

可以跳过

  • 微前端、Monorepo 工程炫技
  • 原生小程序全套
  • 复杂大屏 3D

阶段产出

  • 项目：mes-web + 已有后端
    可演示：登录 → 建物料/设备 → 建工艺 → 开工单 → 报工 → 质检 → 看板统计

阶段 4：完整 Demo 打磨 + 简历包装（4～5 周）

目标不是「功能最多」，而是「主流程闭环 + 能讲清楚」。

必须完成的 Demo 范围（建议就做这些，别膨胀）

  1. 基础数据：车间、产线、物料、设备、用户角色
  2. 工艺路线 + 工序
  3. 生产工单全生命周期
  4. 生产报工（含不良）
  5. 质检录入（合格/不合格，关联工单）
  6. 简单库存台账（领料扣减、完工入库）
  7. 报表：工单进度、不良统计、人员报工量
  8. README：如何启动、账号、演示路径

必须掌握

  • 用真实制造业话术写 README 与简历项目描述
  • 准备 3 个「故障/难点」故事：超报校验、状态流转、权限控制、报表 SQL 等
  • SQL 慢查询基础优化（索引、避免 select *、分页）
  • 部署到一台云主机或内网演示环境（能给面试官看）

了解即可

  • 操作审计日志
  • 数据字典规范化
  • 接口幂等（报工按钮防重复提交）

可以跳过

  • 为了简历硬上微服务、Sa-Token+JWT+OAuth2 全家桶
  • 为了「高大上」上 Elasticsearch

阶段产出

  • GitHub/Gitee 双仓或单仓 monorepo
  • 5～8 分钟演示脚本（自己录一遍）
  • 简历项目条目定稿

阶段 5：面试冲刺（3～4 周，可重叠）

见第 6 节。此阶段并行投递，不必等「完美」。

3. 推荐学习资源（免费/低成本优先）

业务（先看这个）

  • B 站搜索：MES系统讲解、生产执行系统 工单 报工（选播放量高、有界面演示的）
  • 公开资料：各 MES 厂商产品介绍页（只看模块图，别被销售词带跑）
  • 国标/科普文：搜索 GB/T 20720、制造执行系统 MES 功能（浏览即可）

Java / Spring Boot

  • 菜鸟教程 / 廖雪峰 Java 基础（按需查，别通读）
  • 官方文档：Spring Boot Reference
  • MyBatis-Plus 官方文档（CRUD 足够）
  • B 站：搜索 Spring Boot 3 企业后台（选偏 CRUD/权限后台，避开秒杀课）

数据库

  • MySQL 官方文档章节：Data Types、InnoDB、Transaction
  • B 站：MySQL 索引 事务 通俗（各看 1～2 个系列即可）

前端（你已会，补联调）

  • Vue3 官方文档、Element Plus 官方文档
  • 只需补：动态路由权限、文件上传、ECharts 柱状/折线

工具

  • Apifox / Postman
  • Draw.io（流程图、表关系）
  • Navicat / DBeaver

付费课原则：除非你极度需要督学，否则先别买。买的话只买「Spring Boot + Vue 后台」类，别买互联网高并发课。

主项目（P4）建议模块清单

  1. 系统管理：用户、角色、菜单、操作日志
  2. 工厂建模：车间、产线、工位（可简化）
  3. 主数据：物料、设备台账
  4. 工艺：工艺路线、工序、工序-设备关系（简化）
  5. 计划执行：生产工单、下达/开工/完工/关闭
  6. 现场执行：报工、不良登记
  7. 质量管理：质检单、合格判定
  8. 物料：简单领料、库存台账
  9. 看板：工单进度、今日产量、不良 Top

技术栈建议（贴合本地岗）

  • 后端：Java17/11 + Spring Boot + MyBatis-Plus + MySQL + JWT
  • 前端：Vue3 + Element Plus + Axios + ECharts
  • 部署：Nginx + jar + MySQL（一台机即可）

5. 阶段验收标准（不达标别急着进下一阶段）

阶段 0 验收

  • 5 分钟内讲清：MES 与 ERP 区别、工单主流程
  • 能解释：报工、WIP、工艺路线、不良品处理
  • 画出主流程图并给朋友/同事讲通

阶段 1 验收

  • 独立从零搭建 Spring Boot 项目并连上 MySQL
  • 完成登录 + 3 个基础 CRUD，Swagger 可测
  • 手写一版用户-角色权限（不必完美，要能跑）
  • 不看教程能排查：404、500、字段映射错误

阶段 2 验收

  • 工单从创建到完工全状态可走通（接口层）
  • 报工能更新完成数量，并能拦截超额报工
  • 至少 2 个业务在同一事务里成功/失败回滚你能演示
  • 核心表有 ER 图，面试能画出来

阶段 3 验收

  • 前后端联调完整：页面可完成「建工单→报工→质检」
  • 不同角色看到不同菜单/按钮
  • 有一个统计图表页
  • 手机热点下也能演示（说明你部署过或本地启动熟练）

阶段 4 验收

  • README 新人按文档 30 分钟内能跑起来
  • 你能按演示脚本完整走 8 分钟主流程
  • 简历项目描述有业务结果，不只堆技术词
  • 能回答：「如果现场要增加一道质检工序，你改哪些表和接口？」

阶段 5 验收

  • 准备 20 道自问自答（业务 10 + 技术 10）
  • 模拟面试 1 次（可对着录音）
  • 目标公司清单 ≥ 15 家（泰州制造/医药信息化相关）

6. 面试重点准备（泰州制造业 MES / 制造信息化）

高频方向（按优先级）

A. 业务题（往往比算法重要）

  1. MES 和 ERP、WMS 的区别？你们系统管到哪一层？
  2. 生产工单有哪些状态？谁能关闭工单？
  3. 报工时如何防止超报、漏报、重复提交？
  4. 不合格品怎么处理（返工/报废/让步）？系统如何记？
  5. 工艺路线变了，在制工单怎么办？
  6. 设备停机如何影响报工/工单进度？
  7. 你们如何做权限：操作工不能改工艺、质检不能改库存？

B. 技术题（围绕你的 Demo）

  1. 表怎么设计的？工单和报工为什么拆表？
  2. 事务用在哪个接口？不加事务会怎样？
  3. 索引建在哪些查询条件上？
  4. 前后端权限怎么打通？按钮级权限如何做？
  5. 列表分页与导出 Excel 怎么做的？
  6. 和 Vue 协作时接口规范怎么定？
  7. 线上出了「报工数量不对」，你怎么排查？

C. 本地岗位常问软题

  • 能否接受去车间对需求？
  • 是否写过方案/投标？（你可诚实说：更倾向研发交付，方案可配合但不主职）
  • 能否双休/加班文化（主动问清楚）

简历项目描述话术（可直接改）

离散制造 MES 生产执行系统（自研 Demo / 模拟项目）
技术栈：Vue3、Spring Boot、MyBatis-Plus、MySQL、JWT、ECharts
项目描述：面向离散制造车间的生产执行后台，覆盖基础数据、工艺路线、生产工单、现场报工、过程质检与简易库存台账，支撑从工单下达到完工入库的闭环管理。
职责与成果：

  1. 负责后端工单状态流转与报工事务设计，实现超额报工校验与完工数量自动汇总；
  2. 设计物料/设备/工艺等主数据模型，完成后端 API 与权限体系（RBAC）；
  3. 使用 Vue3 搭建车间管理端，完成工单执行、质检录入与产量/不良看板；
  4. 输出工单进度与不良统计报表，支持按车间、日期筛选与导出。

注意：若是自研 Demo，面试别说成「某上市车企真实项目」；可说「面向制造业场景的完整业务系统实践 / 原单位同类后台经验 + 本项目深化」。政企 Vue 经验可写在另一条：「企业后台前端，熟悉流程表单、权限、报表」。

7. 避坑清单

学习上的坑

  1. 一上来刷 JVM/并发/微服务：本地 MES 岗几乎不问，浪费月份。
  2. 只看视频不动手：以接口能跑、页面能点为准。
  3. Demo 做成万能系统：WMS+APS+设备采集全上，最后主流程都讲不顺。
  4. 前端优势用没了：后端还没通就去学 React/移动端，分散火力。
  5. 简历技术栈比项目还长：面试官会按你写的逐项追问。
  6. 裸辞或旷工式学习：泰州岗位窗口窄，现金流断了会被动降薪。

不用死磕的知识点

  • 红黑树、手写线程池、分布式事务 Seata
  • Kafka 原理、Redis 集群槽位
  • DDD 战术百科、六边形架构玄学
  • PLC 梯形图、OPC 驱动开发（除非 JD 点名）

MES 业务重点（比 Java 语法更重要）

  1. 状态：单据状态谁能改、改完影响哪些下游
  2. 数量：计划数、完成数、合格数、不良数，四条数别混
  3. 追溯：哪张报工对应哪个工单/工序/人/时间
  4. 主数据质量：物料编码、设备编码乱了，系统必垮
  5. 现场可用性：按钮少、流程短、容错提示清楚（比 UI 炫更重要）
  6. 和 ERP 边界：MES 不负责财务，别做成「第二个 ERP」

8. 附加加分技能（学习中后期顺带做）

排在主项目闭环之后再做，避免本末倒置。

加分项 做什么 简历怎么写 投入
MES 知识库问答（RAG） 上传 SOP/作业指导书，车间规范问答，带引用片段 「为 MES 增加工艺/SOP 智能问答，支持文档检索与引用回答」 1～2 周
报工防抖/幂等 提交 token 或唯一键，防重复报工 「解决现场重复提交导致产量虚高问题」 2～3 天
Excel 导入导出 物料/工单批量导入 「支持主数据批量导入，降低实施初期录入成本」 3～5 天
操作审计 关键单据变更记日志 「关键生产数据变更可追溯」 2～3 天
简易安灯/异常提报 设备故障一键上报+列表 「支持现场异常提报与处理闭环」 3～5 天
Docker Compose mysql + 后端一键起 「提供容器化本地部署方案」 1～2 天

AI 模块边界（重要）

  • 做「文档问答 / 工单助手」即可，别做成「AI 排产算法专家」
  • 技术点：文档切分、向量检索、权限内检索、回答带来源
  • 本地岗加分逻辑：证明你能把 AI 接到现有业务系统，不是会玩聊天机器人

  • 周末：画主流程图，写词汇表

  • 周末：把权限后台做完并自测

  • 周末：打通工单与报工事务

  • 平日：前端页面
  • 周末：联调主流程 + 看板

第 23～27 周（阶段 4）

  • 补齐质检/库存/README/部署
  • 写简历项目描述，录演示

  • 刷题+模拟面试
  • 开始投：制造企业信息化、MES 实施商本地研发、药企/工厂数字化岗

10. 求职投递提醒（配合学习）

优先投

  • 制造企业甲方信息化/数字化（双休概率更高）
  • 有 MES/MOM 产品的本地或服务泰州的软件公司研发岗

慎投

  • 纯售前/投标岗、长期驻场且写方案为主的实施岗
  • 薪资长期卡在 6～8k 的小作坊（练手可以，转正谈判难到 12k）

谈薪话术锚点

  • 用「全栈 + 制造业业务闭环 + 可维护交付」谈，不谈「我会微服务」
  • 问清：是否双休、是否写投标、是否驻厂、13/14 薪

一句话执行口令

在职每月只抓一件事：先会讲 MES 流程，再能写工单报工接口，再用 Vue 把闭环点出来；AI 问答最后再挂上去当亮点。
