章节 标记 说明

11～14、16、20、21、24（阶段1大体跳过）

章节 标记 说明
11 单元测试 👀 后期抽 1 天学 JUnit 基础即可
12 正则 👀 校验编码时当手册
13 加密与安全 👀 密码哈希以后用 Spring Security/工具；别啃完整章
14 多线程几乎全部 ⏭️/🚫 阶段1不学；最多知道「别自己乱开线程」
16 网络编程 ⏭️/🚫 TCP/UDP/邮件/RMI 全跳；HTTP 交给 Spring
20 设计模式全书 ⏭️ 以后只按需看：单例/策略/状态/模板方法
21 Servlet/JSP 老 Web ⏭️ 直接学 Spring Boot，别先走史前路线
24 Spring Cloud / 交易引擎 🚫 一线互联网/分布式，与泰州 MES 无关

15、17、18、19（衔接工程）

章节 标记 说明
15.1～15.3 Maven 介绍/依赖/构建 ✅ 进 Spring Boot 前必看
15.4～15.7 插件/模块/mvnw/发布 👀
17.1～17.3 XML/DOM/SAX ⏭️
17.4～17.5 Jackson / JSON ✅ 接口返回 JSON
18 JDBC 全章 👀 快速扫事务概念，实作交给 MyBatis-Plus
19.1～19.2 Lambda/方法引用 ✅
19.3 Stream（map/filter/toList） ✅ 常用即可，reduce 等可略

22～23 Spring / Spring Boot（阶段1后半主战场）

章节 标记 说明
22.1 IoC 容器核心 ✅ 理解依赖注入
22.2 AOP 👀 知日志/事务靠它；别先手写复杂切面
22.3.1～22.3.3 JDBC/事务/DAO 👀 建立概念
22.3.4～22.3.5 Hibernate/JPA ⏭️ 你走 MyBatis 路线
22.3.6 集成 MyBatis ✅
22.3.7 设计 ORM ⏭️
22.4.1～22.4.2 MVC / REST ✅
22.4.3～22.4.8 Filter/拦截/CORS 等 👀 CORS、拦截器做前后端分离时看
22.5 邮件/JMS/JMX 等 ⏭️ Scheduler 以后做定时任务再看
23.1～23.3 第一个应用/打包 ✅ 语法够用后尽早转到这里
23.4～23.9 Actuator/Profiles/配置等 👀 做项目时按需
23.10.1 Open API ✅ 接口文档
23.10.2 Redis 👀 登录态/字典缓存
23.10.3～23.10.5 MQ/Kafka 🚫 阶段1别碰

  3. ✅ 3.2.1、3.2.4～3.2.6、3.2.9
  4. ✅ 第 4 章异常（到 4.5）+ 4.10 日志
  5. ✅ 第 7 章泛型 7.1～7.2 + 第 8 章 List/Map/Set
  6. ✅ 第 10 章 LocalDateTime + Formatter
  7. ✅ 第 19 章 Lambda + Stream 常用
  8. ✅ 第 15 章 Maven 基础
  9. 👀 第 18 章 JDBC 事务概念；✅ 17.4/17.5 JSON
