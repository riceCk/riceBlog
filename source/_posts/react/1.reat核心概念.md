## 1.组件与事件绑定
在 *React* 中绑定事件的写法如下：

```html
<button onClick={activateLasers}>Activate Lasers</button>
```
在 *React* 中无法通过 *return false* 来阻止默认行为，所以只有使用 *e.preventDefault* 的方式来阻止默认行为。

```js
function Form() {
  function handleSubmit(e) {
    e.preventDefault();
    console.log('You clicked submit.');
    console.log(e.nativeEvent, '原生事件对象');
  }

  return (
    <form onSubmit={handleSubmit}>
      <button type="submit" onClick={() => handleSubmit('hello')}>Submit</button>
    </form>
  );
}
```

## 2.组件状态与数据的传递

### 2.1 状态的定义

早期类组件被称之为有状态组件，就是因为在类组件中能够维护组件数据。

```js
class 类名 extends React.Component{
  constructor(){
    super();
    // 设置组件自身的数据状态
    this.state = {
      xxx : xxx
    }
  }
  render(){
    return (
    // 通过 {this.state.xxx} 来获取状态数据
    )
  }
}

// 或者
class 类名 extends React.Component{
  state = {
      xxx : xxx
  }
  render(){
    return (
    // 通过 {this.state.xxx} 来获取状态数据
    )
  }
}
```

### 2.2 状态的修改

不要直接去修改状态值，而是应该通过 *setState* 方法修改组件的 *state* 状态数据。

```js 
this.setState({
  xxx: 新值
})

this.setState({
  xxx: 新值
}, () => {
  console.log('修改后回调')
})

// 让异步变成同步
this.setState(pre => ({
  xxx: pre.xxx + 新值
}))
```

**setState**，它对状态的改变，**可能**是异步的。
> 如果改变状态的代码处于某个 *HTML* 元素的事件中，则其是异步的，否则是同步

最佳实践：
1. 把所有的 *setState* 当作是异步的
2. 永远不要信任 *setState* 调用之后的状态
3. 如果要使用改变之后的状态，需要使用回调函数（*setState* 的第二个参数）
4. 如果新的状态要根据之前的状态进行运算，使用函数的方式改变状态（*setState* 的第一个函数）

*React* 会对异步的 *setState* 进行优化，将多次 *setState* 进行合并（将多次状态改变完成后，再统一对 *state* 进行改变，然后触发 *render*）
```js
this.setState(pre => ({
  name: pre.name + "1"
}), () => {
  // setState合并多次状态，所以这边是最终展示的数据
  console.log(this.state.name);
})
this.setState(pre => ({
  name: pre.name + "1"
}))
this.setState(pre => ({
  name: pre.name + "1"
}))
```

### 2.3 *props*

如果是函数组件，*props* 作为函数的一个参数传入：

```js
function 组件名(props) {
  return (
    // 一段 JSX
    // 通过 props.xxx 获取传入的值
    <div>
      <p>姓名：{props.name}</p>
      <p>年龄：{props.age}</p>
      <p>性别：{props.gender}</p>   
    </div>
  );
}
```

如果是类组件，则需要在 *constructor* 中将 *props* 通过 *super* 传递给父类，然后通过 *this.props* 的方式来获取传入的值：

```js
class 组件名 extends React.Component {
  constructor(props) {
    super(props);
  }
  render() {
    return (
       // 一段 JSX
    	 // 通过 this.props.xxx 获取传入的值
        <div>
          <p>姓名：{this.props.name}</p>
          <p>年龄：{this.props.age}</p>
          <p>性别：{this.props.gender}</p>   
        </div>
     );
	}
}
```

通过 *props.children*，可以实现类似于 *Vue* 中插槽的功能，例如：

```js
class 组件B extends React.Component{
  constructor(props){
    super(props);
  }
  render(){
    return (
      <div>
          {this.props.children}
      </div>
    );
  }
}
class 组件A extends React.Component{
  constructor(props){
    super(props);
  }
  render(){
    return (
      <组件B>
        <p>Hello, React</p>
        <p>Hello, Redux</p>
        <p>Hello, Facebook</p>
        <p>Hello, Google</p>
      </组件B>
    );
  }
}
```

### 2.5 状态提升例子
app.js组件
```js
import React from "react";
import Moneny from './component/Moneny';

class App extends React.Component {
  state = {
    dollar: '',
    rmb: ''
  }
  handleDollar = (value) => {
    this.setState({
      dollar: value,
      rmb: value * 7
    })
  }
  handleRmb = (value) => {
    this.setState({
      rmb: value,
      dollar: value / 7
    })
  }
  render() {
    return (
      <div>
        <Moneny text="美元" moneny={this.state.dollar} onChange={this.handleDollar}></Moneny>
        <Moneny text="人民币" moneny={this.state.rmb} onChange={this.handleRmb}></Moneny>
      </div>
    )
  }
}

export default App;
```

Moneny组件

```js
function Moneny(props) {
  const handleChange = (e) => {
    props.onChange && props.onChange(e.target.value)
  }

  return (
    <fieldset>
      <legend>{props.text}:</legend>
      <input type="text" value={props.moneny} onChange={handleChange} />
    </fieldset>
  )
}
export default Moneny;
```

## 3.表单

### 3.1 受控组件

原理就是state数据管理

```js
import React from "react";
// 类组件
class App extends React.Component {
  state = {
    value : ""
  }
  handleChange = (e) => {
    this.setState({
      value : e.target.value
    })
  }
  clickHandle = () => {
    // 提交整个表单
    console.log(`你要提交的内容为：${this.state.value}`);
  }
  render() {
    return (
      <div>
        <input type="text" value={this.state.value} onChange={this.handleChange}/>
        <button onClick={this.clickHandle}>提交</button>
      </div>
    )
  }

}
export default App;
```

### 3.2 非受控组件

在某些特殊情况下，需要使用以前传统的 *DOM* 方案进行处理，此时替代的方案就是非受控组件,通过**ref**

```js
import React from "react";

class App extends React.Component {
  constructor(props) {
    super(props);
    this.inputCon = React.createRef()
  }
  render() {
    return (
      <div>
        {/* 一旦你用了 value，React 会认为你这是一个受控组件 */}
        {/* 如果想要给默认值，使用 defaultValue */}
        <input type="text" ref={this.inputCon} defaultValue="123"></input>
        <button onClick={() => console.log(this.inputCon.current.value)}>Log Value</button>
      </div>
    )
  }
}

export default App;
```
