# ⏱️ 超步

一个节点拉出多条出边，叫扇出。多条入边汇到同一个节点，叫扇入。LangGraph 在同一轮里用并发去跑这些分支：一个执行单元来回切换，不是多核真正同时算。

- 并发：一个服务员轮流照看三桌
- 并行：三个服务员各看一桌

> 💡 LangGraph 这里用的是并发。

![扇出](https://xiejie-typora.oss-cn-chengdu.aliyuncs.com/2025-11-10-034622.png)

![扇入](https://xiejie-typora.oss-cn-chengdu.aliyuncs.com/2025-11-10-034752.png)

下面 A 同时连到 B 和 C，两边都结束才进 D。B 睡 2.5 秒、C 睡 1 秒，日志里能看到它们在同一轮开始，D 要等较慢的 B。

```js
import { StateGraph, START, END } from "@langchain/langgraph";
import { z } from "zod/v4";
import { registry } from "@langchain/langgraph/zod";

const Schema = z.object({
  a: z.string().optional(),
  b: z.string().optional(),
  c: z.string().optional(),
  t0: z.number().optional(),
  logs: z.array(z.string()).register(registry, {
    reducer: {
      fn: (oldVal, newVal) => oldVal.concat(newVal),
    },
    default: () => [],
  }),
});

const sleep = (ms) => new Promise((r) => setTimeout(r, ms));
const fmt = (t0) => `${t0 !== undefined ? Date.now() - t0 : 0}ms`;

const graph = new StateGraph(Schema)
  .addNode("A", async () => {
    console.log("运行 A");
    return {
      a: "A 节点执行后的结果",
      t0: Date.now(),
      logs: ["【A】开始（+0ms）", "【A】结束（+0ms）"],
    };
  })
  .addNode("B", async (state) => {
    console.log("运行 B");
    const start = fmt(state.t0);
    await sleep(2500);
    return {
      b: "B 节点执行后的结果",
      logs: [`【B】开始(+${start})`, `【B】结束(+${fmt(state.t0)})`],
    };
  })
  .addNode("C", async (state) => {
    console.log("运行 C");
    const start = fmt(state.t0);
    await sleep(1000);
    return {
      c: "C 节点执行后的结果",
      logs: [`【C】开始(+${start})`, `【C】结束(+${fmt(state.t0)})`],
    };
  })
  .addNode("D", async (state) => {
    console.log("运行 D");
    const summary = `D 已运行，b=${state.b ?? "none"}，c=${state.c ?? "none"}`;
    return {
      logs: [summary, `【D】结束(+${fmt(state.t0)})`, "整个流程结束"],
    };
  })
  .addEdge(START, "A")
  .addEdge("A", "B")
  .addEdge("A", "C")
  .addEdge("B", "D")
  .addEdge("C", "D")
  .addEdge("D", END)
  .compile();
```

## 超步是什么

超步是一轮统一调度。这一轮里能跑的节点一起并发，轮次结束做一次全局同步，再进入下一轮。这个想法来自 Pregel 那类图计算：同一轮互不影响，轮与轮之间才看见对方写好的状态。

![超步](https://xiejie-typora.oss-cn-chengdu.aliyuncs.com/2025-11-10-034128.png)

所以上面的例子是三轮：A 自己一轮；B 和 C 同一轮；D 再一轮。

# 边

四种：

1. 普通边：`addEdge("nodeA", "nodeB")`
2. 条件边：跑完再决定去哪
3. 入口：`START`
4. 条件入口：从 `START` 就分流

## 条件边

```js
graph.addConditionalEdges("nodeA", routingFunction, mapping);
```

- 第一个参数：从哪个节点出去
- `routingFunction(state)`：看当前状态，返回一个去向
- `mapping` 可选：把返回值翻译成节点名。这样路由函数可以只返回 `true` / `false`，不必写死节点名

```js
function shouldSearch(state) {
  return Boolean(state.query?.trim());
}
function route(state) {
  if (state.needTools) return "tools";
  if (state.done) return "stop";
  return "finalize";
}
function fanOut() {
  return ["fetchProfile", "fetchOrders"]; // 下一步同时跑两个
}

graph.addConditionalEdges("nodeA", shouldSearch, {
  true: "nodeB",
  false: "nodeC",
});
```

按 `state.path` 走 B 或 C，两边都汇到 D：

```js
const graph = new StateGraph(Schema)
  .addNode("A", async () => ({ a: "A 的结果", logs: ["A 完成"] }))
  .addNode("B", async () => ({ a: "B 的结果", logs: ["B 完成"] }))
  .addNode("C", () => ({ a: "C 的结果", logs: ["C 完成"] }))
  .addNode("D", () => ({ a: "D 的结果", logs: ["D 完成"] }))
  .addEdge(START, "A")
  .addConditionalEdges("A", (state) => (state.path === "B" ? "B" : "C"))
  .addEdge("B", "D")
  .addEdge("C", "D")
  .addEdge("D", END)
  .compile();
```

条件入口就是把起点写成 `START`：

```js
graph.addConditionalEdges(START, routingFunction, {
  true: "nodeB",
  false: "nodeC",
});
```

# 实战循环

条件边的目标可以指回自己。`count` 还没到上限就再进 `increment`，到了就去 `END`。

```js
function buildGraph(maxCount) {
  async function increment(state) {
    await sleep(1500);
    return { count: state.count + 1 };
  }

  function routeFunc(state) {
    return state.count < maxCount ? "true" : "false";
  }

  return new StateGraph(Schema)
    .addNode("increment", increment)
    .addEdge(START, "increment")
    .addConditionalEdges("increment", routeFunc, {
      true: "increment",
      false: END,
    })
    .compile();
}
```
