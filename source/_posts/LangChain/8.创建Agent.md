# 🤖 创建 Agent

Agent 自己决定要不要调工具、调哪一个、参数是什么，再根据工具结果继续说。

## LangChain Hub

提示词仓库，用法接近 Hugging Face Hub。`pull(identifier)` 按名字把一份 prompt 或 chain 拉下来。

- `"hwchase17/react"`
- `"hwchase17/openai-tools-agent"`
- `"org_name/custom_prompt"`

拉到的如果是提示词，就是 `PromptTemplate` 或 `ChatPromptTemplate`；如果是链，就是一个 Runnable。

```js
import { pull } from "langchain/hub";

const prompt = await pull("hwchase17/react");
```

`hwchase17/react` 规定了模型必须按这个格式说话：Thought → Action → Action Input → Observation，可以重复多次，最后给 Final Answer。模板里的 `{tools}`、`{tool_names}`、`{input}`、`{agent_scratchpad}` 由执行器填。

## Tools

工具就是一个带名字、说明和参数结构的函数。`tool()` 配上 zod，就能交给 Agent。

```js
import { tool } from "@langchain/core/tools";
import { z } from "zod";

const weatherTool = tool(
  async (city) => `${city}：多云转晴，28℃ / 20℃（示例数据）`,
  {
    name: "weather",
    description: "查询城市天气。输入城市名。",
    schema: z.string(),
  },
);
```

模型侧也可以直接挂 OpenAI 风格的 function schema，用 `.withConfig({ tools })`。上面的 `tool()` 是给 Agent 用的封装，两边描述的是同一件事。

## createReactAgent

ReAct = Reasoning + Acting。任何能生成文本的模型都能用，不要求原生工具调用。

必填三项：

- `llm`：聊天模型或文本模型
- `tools`：工具列表
- `prompt`：ReAct 模板，可以直接 `pull("hwchase17/react")`。这份模板决定了 agent 要哪些输入变量

```js
const prompt = await pull("hwchase17/react");
const llm = new ChatOpenAI({
  model: "gpt-4o-mini",
  temperature: 0,
});
const tools = [weatherTool, weekdayTool];

const agent = await createReactAgent({ llm, tools, prompt });
```

一轮内部是：预处理 → 套模板 → 模型补全 → 解析成 `AgentAction` 或 `AgentFinish`。

## AgentExecutor

执行器拿着 agent 和 tools 做外层循环：

1. 问 agent。它返回 `AgentAction`（调哪个工具、参数是什么）或 `AgentFinish`（可以结束了）
2. 拿到 `AgentAction` 就按 `action.tool` 找到工具，校验参数，执行，得到 observation
3. 把 `{ action, observation }` 记成一步，并写进 `agent_scratchpad`，下一轮还给 agent
4. 遇到 `AgentFinish`，或达到 `maxIterations`，就停

```js
const executor = new AgentExecutor({
  agent,
  tools,
  returnIntermediateSteps: true,
  maxIterations: 5,
  handleParsingErrors: true,
});
```

## createToolCallingAgent

不走「Thought / Action」这套文本格式，而是让模型直接输出结构化的工具调用。模型要本身支持 function calling / tool calling。

| | `createToolCallingAgent` | `createReactAgent` |
|---|---|---|
| 机制 | 模型原生的工具调用 | ReAct：先想，再行动 |
| 推理 | 一步决定调不调工具 | Thought → Action → Observation，可重复 |
| 模型 | 要支持结构化工具调用 | 能生成文本即可 |
| 次数 | 通常 1～2 次 | 可能转好几轮 |
| 过程是否可见 | 直接给出调用或回答 | 推理链能打印出来 |
| 适合 | 要快、要上线 | 教学、调试、模型不支持工具调用 |

## streamEvents

`invoke()` 和 `stream()` 要等结果（或等文本流）。`streamEvents()` 把执行过程里的事件逐条送出来，适合调试和前端实时展示。

```js
const events = await executor.streamEvents(
  { input, chat_history },
  { version: "v2" },
);

for await (const event of events) {
  if (event.event === "on_chat_model_stream") {
    process.stdout.write(event.data.chunk.content);
  }
  if (event.event === "on_tool_start") {
    console.log(`正在调用工具: ${event.name}`);
  }
  if (event.event === "on_tool_end") {
    console.log("工具结果:", event.data.output);
  }
}
```
