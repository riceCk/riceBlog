# 📖 基础认知

## 什么是 LangChain

LangChain 用来搭建大语言模型应用。它把模型、提示词、解析器这些部分做成标准组件，可以像搭积木一样串起来。

| 包名 | 作用 | 类比 |
|------|------|------|
| `@langchain/core` | 最底层的抽象：Runnable、Prompt、OutputParser | 地基 |
| `@langchain/community` | 第三方集成：向量库、文档加载器、各种模型 API | 插件市场 |
| `langchain` | 高阶封装：Chain、Agent、Tool | 精装房 |
| `@langchain/ollama` | 本地 Ollama 模型的具体实现 | 一块具体的建材 |

## 模型分类

LangChain 里常见两类模型：

| 类型 | 适用场景 | 输入 | 代表 |
|------|---------|------|------|
| 文本补全模型 | 一次性生成、简单问答 | 纯字符串 | GPT-2、早期 Llama |
| 对话模型（Chat Model） | 多轮对话、角色设定 | 带角色的消息数组 | GPT-3.5/4、Llama3、Claude |

```js
// 文本补全：直接传字符串
import { Ollama } from "@langchain/ollama";
const model = new Ollama({ model: "llama3" });
const res = await model.invoke("你是一位助手");

// 对话模型：传消息数组
import { ChatOllama } from "@langchain/ollama";
import { HumanMessage } from "@langchain/core/messages";
const chatModel = new ChatOllama({ model: "llama3" });
const chatRes = await chatModel.invoke([new HumanMessage("你好")]);
```

后面的笔记用的是 `ChatOllama`，属于对话模型，输入要写成消息对象，不是一整段纯文本。

## 两种调用

```js
// 一次拿回完整结果
const res = await model.invoke(prompt);
console.log(res);

// 流式输出，适合打字机效果
const stream = await model.stream(prompt);
for await (const chunk of stream) {
  process.stdout.write(chunk.content);
}
```

## 缓存

缓存解决三件事：重复问题不用再打模型、少花远程 API 的钱、并发时少压模型。

精确匹配的开关：

```js
const model = new Ollama({
  model: "llama3",
  cache: true,
});
```

官方默认的缓存键算法会提示不够安全。可以自己实现一个缓存，用 SHA-256 做键。现在不必上，知道思路即可：

```js
// utils.js
import crypto from "crypto";

export class SecureCache {
  constructor() {
    this.cache = new Map();
  }

  _createSecureKey(prompt, llmString) {
    const data = `${prompt}-${llmString}`;
    return crypto.createHash("sha256").update(data).digest("hex");
  }

  async lookup(prompt, llmString) {
    return this.cache.get(this._createSecureKey(prompt, llmString));
  }

  async update(prompt, llmString, result) {
    this.cache.set(this._createSecureKey(prompt, llmString), result);
  }

  async clear() {
    this.cache.clear();
  }
}
```

```js
// index.js
import { SecureCache } from "./utils.js";

const model = new Ollama({
  model: "llama3",
  cache: new SecureCache(),
});
```

精确匹配要求问题一字不差。下面这个例子改成向量相似度：问题意思接近就命中缓存。

```bash
pnpm add cosine-similarity
```

```js
import { ChatOllama, OllamaEmbeddings } from "@langchain/ollama";
import cosineSimilarity from "cosine-similarity";

const model = new ChatOllama({
  model: "llama3",
  stream: true,
});

const embedder = new OllamaEmbeddings({
  model: "nomic-embed-text",
});

const cache = [];

async function callLLM(inputText, threshold = 0.7) {
  const queryEmbedding = await embedder.embedQuery(inputText);

  for (const item of cache) {
    const score = cosineSimilarity(queryEmbedding, item.embedding);
    if (score >= threshold) {
      return process.stdout.write(item.response);
    }
  }

  let fullResponse = "";
  const stream = await model.stream(inputText);
  for await (const chunk of stream) {
    process.stdout.write(chunk.content);
    fullResponse += chunk.content;
  }

  cache.push({
    input: inputText,
    embedding: queryEmbedding,
    response: fullResponse,
  });
}

const q1 = "请你使用中文介绍下大象这种动物";
const q2 = "请你使用中文介绍下大象这种动物";
await callLLM(q1);
console.log("\n\n第二次调用：");
await callLLM(q2);
```
