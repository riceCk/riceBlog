## 📖 LangChain 基础认知

### 1.1 什么是 LangChain？

LangChain 是一个用于构建大语言模型（LLM）应用的开发框架。它提供了标准化的接口和组件，让你可以像"搭积木"一样组合各种功能。

**核心模块生态：**

| 包名 | 作用 | 类比 |
|------|------|------|
| `@langchain/core` | 最基础的抽象能力（Runnable、Prompt、OutputParser） | 地基 |
| `@langchain/community` | 第三方集成（向量数据库、模型API、文档加载器） | 插件市场 |
| `langchain` | 高阶封装（Chains、Agents、Tools） | 精装房 |
| `@langchain/ollama` | Ollama 模型的具体实现 | 具体的建材 |


### 1.2 模型分类（重要！）

LangChain 支持两类语言模型：

| 类型 | 适用场景 | 输入格式 | 代表模型 |
|------|---------|---------|---------|
| **文本补全模型** | 简单的文本生成、问答 | 纯文本字符串 | GPT-2, 基础版 Llama |
| **对话模型（Chat Model）** | 多轮对话、角色扮演 | 消息对象数组（带角色） | GPT-3.5/4, Llama3, Claude |

```bash
# ❌ 文本补全模型 - 直接传字符串
import { Ollama } from "@langchain/ollama";
const model = new Ollama({ model: "llama3" });
const res = await model.invoke("你是一位助手"); # 传字符串

# ✅ 对话模型 - 传消息对象
import { ChatOllama } from "@langchain/ollama";
const chatModel = new ChatOllama({ model: "llama3" });
const res = await chatModel.invoke([new HumanMessage("你好")]); # 传消息数组
```
**关键点：**你的代码用的是 ChatOllama，属于**对话模型**，所以要用消息对象（Message），而不是纯文本。

### 1.3 两种调用方式
```bash
# 方式一：普通调用（一次性返回完整结果）
const res = await model.invoke(prompt);
console.log(res);

# 方式二：流式调用（逐字输出，适合打字机效果）
const stream = await model.stream(prompt);
for await (const chunk of stream) {
  process.stdout.write(chunk.content); # 逐块输出
}
```
### 1.4 缓存机制
缓存的作用：
* 1.提升速度：重复问题直接命中缓存，无需重新调用模型
* 2.降低成本：减少 API 调用次数（对远程模型尤其重要）
* 3.减轻负担：减少系统负载，提升并发性能

**简单缓存（精确匹配）：**
```bash
# 下载cache
# pnpm add cache
const model =new Ollama({
  model: "llama3",
  cache: true, # 开启缓存
})
```

2.解决缓存默认使用的哈希算法不够安全问题
自定义缓存类，解决官方提示问题，现在不需要解决，可以看下思路
```bash
# 创建utils.js方法
import crypto from "crypto";

export class SecureCache {
  constructor () {
    this.cache = new Map(); # 使用 Map 来存储缓存数据
  }

  # 生成缓存键
  _createSecureKey (prompt, llmString) {
    const data = `${prompt}-${llmString}`;
    return crypto.createHash("sha256").update(data).digest("hex");
  }

  # 获取缓存数据
  async lookup(prompt, llmString) {
    const key = this._createSecureKey(prompt, llmString);
    return this.cache.get(key);
  }

  async update(prompt, llmString, result) {
    const key = this._createSecureKey(prompt, llmString);
    this.cache.set(key, result);
  }

  async clear() {
    this.cache.clear();
  }
}

# index.js 使用
import {SecureCache} from "./utils.js"; 

const sc = new SecureCache();

const model =new Ollama({
  model: "llama3",
  cache: sc,
})
```

**综合案例**
1. 提升响应速度：重复问题无需重新调用模型，直接命中缓存
2. 降低调用成本，尤其对于调用远程的，可节省费用
3. 避免冗余：减少系统负担，提高整体并发性能

```bash
# 补充安装，对比向量
# pnpm add cosine-similarity


import { ChatOllama, OllamaEmbeddings } from "@langchain/ollama";
import cosineSimilarity from "cosine-similarity";

const model = new ChatOllama({
  model: "llama3",
  stream: true,
});

# 负责将文本装换成向量的模型
const embedder = new OllamaEmbeddings({
  model: "nomic-embed-text",
});

const cache = []; # 用于存储缓存的向量和对应的文本

async function callLLM(inputText, threshold = 0.7) {
  # 1. 将输入文本转换为向量
  const queryEmbedding = await embedder.embedQuery(inputText);

  # 2. 检查缓存中是否有相似的向量
  # 当前用户问题的向量和缓存里面的每一项做比较
  for (const item of cache) {
    const score = cosineSimilarity(queryEmbedding, item.embedding); # 计算相似度
    if (score >= threshold) {
      # `命中缓存，使用缓存的响应， 相似度：${score}`
      return process.stdout.write(item.response); # 返回缓存的响应
    }
  }
  let fullResponse = "";
  const stream = await model.stream(inputText); # 调用模型获取响应
  for await (const chunk of stream) {
    process.stdout.write(chunk.content); # 实时输出流数据
    fullResponse += chunk.content; # 拼接完整响应
  }

  cache.push({
    input: inputText, # 存储原始输入文本
    embedding: queryEmbedding, # 存储向量
    response: fullResponse, # 存储模型的响应
  });
}

const q1 = "请你使用中文介绍下大象这种动物";
const q2 = "请你使用中文介绍下大象这种动物";
await callLLM(q1);

console.log("\n\n第二次调用：");
await callLLM(q2);
```
