# 🔗 LCEL

LCEL（LangChain Expression Language）用 `.pipe()` 把提示词、模型、解析器串成一条链。能被串起来的模块都实现同一个接口：`Runnable`。

```js
import { ChatOllama } from "@langchain/ollama";
import { PromptTemplate } from "@langchain/core/prompts";
import { StringOutputParser } from "@langchain/core/output_parsers";

const prompt = PromptTemplate.fromTemplate("请使用中文解释：{question}");
const model = new ChatOllama({
  model: "llama3",
  temperature: 0.7,
});
const parser = new StringOutputParser();

const chain = prompt.pipe(model).pipe(parser);
const res = await chain.invoke({ question: "js闭包" });
```

`.pipe()` 就是模块之间的数据通道：

- `prompt` 把原始输入填成提示词
- `model` 根据提示词生成回答
- `parser` 把回答收成字符串

常用方法：`invoke` 一次拿完整结果，`stream` 流式输出，`batch` 一次处理多条输入，`pipe` 负责把它们接上。

```js
const inputs = [
  { question: "闭包" },
  { question: "原型链" },
  { question: "事件循环" },
];
const res = await chain.batch(inputs);
```

# Runnable

提示词、模型、解析器几乎都是 Runnable，所以能插进同一条链。

## RunnableLambda

把一个普通函数包成 Runnable。`pipe()` 如果直接收到函数，内部也会帮你做这件事。

```js
import { RunnableLambda } from "@langchain/core/runnables";

const runnableFn = RunnableLambda.from((text) => text.toUpperCase());
const result = await runnableFn.invoke("hello");
```

插在链尾做后处理，例如把关键词包一层标记：

```js
const pt = PromptTemplate.fromTemplate("请使用中文解释：{topic}");
const model = new ChatOllama({ model: "llama3", temperature: 0.7 });
const parser = new StringOutputParser();
const highlight = RunnableLambda.from((text) => text.replace(/闭包/g, "*&*闭包"));

const result = await pt.pipe(model).pipe(parser).pipe(highlight).invoke({ topic: "闭包" });
```

同样的插槽还可以放日志、翻译、敏感词过滤，或者一个决定要不要中断的判断。

`pipe()` 能接收三种东西：

- Runnable：最常用
- 普通函数：自动包成 `RunnableLambda`
- 对象：把同一份输入分给多个链，返回一个对象

```js
const chain1 = PromptTemplate.fromTemplate("请用中文 2-3 句概括以下主题：{input}")
  .pipe(model)
  .pipe(parser);
const chain2 = PromptTemplate.fromTemplate("请用中文从以下主题提取 5 个关键词，用逗号隔开：{input}")
  .pipe(model)
  .pipe(parser);

const chain = RunnableLambda.from((x) => x).pipe({
  summary: chain1,
  keywords: chain2,
});
const result = await chain.invoke({ input: "闭包" });
```

## RunnableMap

`RunnableMap`（也叫 `RunnableParallel`）让多条子链同时跑，结果合成一个对象。

```js
import { RunnableMap } from "@langchain/core/runnables";

const joke = PromptTemplate.fromTemplate("请用中文讲一个关于{topic}的笑话")
  .pipe(model)
  .pipe(parser);
const poem = PromptTemplate.fromTemplate("请用中文写一首关于{topic}的诗")
  .pipe(model)
  .pipe(parser);

const chain = RunnableMap.from({ joke, poem });
const result = await chain.invoke({ topic: "小狗" });
```

它的 `.stream()` 不会把几条子链的增量拼成一条流。每条子链各自是一个异步迭代器。

## RunnableSequence

`.pipe()` 是一个接一个串。步骤多了，用 `RunnableSequence.from([...])` 把顺序写成数组，读起来更清楚。下面和 `pt.pipe(model).pipe(parser).pipe(highlight)` 是同一条链。

```js
import { RunnableSequence } from "@langchain/core/runnables";

const chain = RunnableSequence.from([pt, model, parser, highlight]);
const result = await chain.invoke({ topic: "闭包" });
```

## RunnablePassthrough

原样把输入传下去，同时可以做副作用：打日志、埋点、写库。`.assign()` 往这份数据上加字段，类似 `Object.assign`。

```js
import { RunnablePassthrough } from "@langchain/core/runnables";

const logger = new RunnablePassthrough({
  func: async (input) => {
    console.log("收到输入：", input);
  },
});

const injector = RunnablePassthrough.assign({
  timestamp: async () => new Date().toISOString(),
  meta: async () => ({
    region: "us-east",
    requestId: "req-456",
  }),
});
```

一条带日志和用户 id 的链：

```js
const logFunc = new RunnablePassthrough({
  func: async (input) => {
    console.log("用户提的问题为：", input.query);
  },
});

const injector = RunnablePassthrough.assign({
  userId: async (input) => input.userId,
});

const pt = PromptTemplate.fromTemplate(
  "请使用中文帮用户{userId}解答：{query}。回答时以「亲爱的{userId}」开头",
);
const model = new ChatOllama({ model: "llama3", temperature: 0.7 });
const parser = new StringOutputParser();

const chain = RunnableSequence.from([logFunc, injector, pt, model, parser]);
const stream = await chain.stream({
  query: "闭包",
  userId: "user-12345",
});
for await (const chunk of stream) {
  process.stdout.write(chunk);
}
```

# 条件路由

先看输入，再决定走哪条子链。不要用一个提示词处理所有问题。

两种写法：

1. `RunnableBranch`：按顺序匹配，像 if / else
2. `RunnableLambda`：在函数里直接返回要执行的子链

## RunnableBranch

```js
new RunnableBranch({ branches, default });
```

`branches` 里每一项是「条件函数 + 子链」。都不命中就走 `default`。

下面先用一条分类链给问题打标签，再按标签分到物理、数学或其他链。

```js
const model = new ChatOllama({ model: "llama3", temperature: 0.7 });
const parser = new StringOutputParser();

const physicsChain = ChatPromptTemplate.fromTemplate(
  `你是一位物理老师，用中文回答物理问题。不知道就回答不知道。
问题：{input}`,
).pipe(model).pipe(parser);

const mathChain = ChatPromptTemplate.fromTemplate(
  `你是一位数学老师，用中文回答数学问题。不知道就回答不知道。
问题：{input}`,
).pipe(model).pipe(parser);

const otherChain = ChatPromptTemplate.fromTemplate(
  `你是一个 AI 助手，用中文回答下面的问题。
问题：{input}`,
).pipe(model).pipe(parser);

const classifyChain = ChatPromptTemplate.fromMessages([
  ["system", `你是一个只输出标签的分类器。
把用户问题分成：数学、物理、其他。
只能输出这三个词里的一个，不要解释。不确定就输出：其他`],
  ["human", "问题：{input}\n现在只输出分类："],
]).pipe(model).pipe(parser);

const answerBranch = RunnableBranch.from([
  [(input) => input.topic.includes("物理"), physicsChain],
  [(input) => input.topic.includes("数学"), mathChain],
  otherChain,
]);

const finalChain = RunnableSequence.from([
  RunnablePassthrough.assign({
    topic: classifyChain,
  }),
  new RunnablePassthrough({
    func: async (input) => {
      console.log(input); // { input: "什么是经典力学", topic: "物理" }
      return input;
    },
  }),
  answerBranch,
]);

await finalChain.invoke({ input: "什么是经典力学" });
await finalChain.invoke({ input: "对 y = x 求导的结果是多少" });
await finalChain.invoke({ input: "你好，你是谁？" });
```
