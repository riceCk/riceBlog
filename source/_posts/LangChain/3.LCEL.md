# LCEL
LangChain Expression Language,是LangChain提供的一种声明式构建**链式**，调用的流程方式，它允许开发者`.pipe()`操作符将不同模块（比如提示模块、模型、解析器等）连接在一起形成一个完整的“链（Chain）”
LCEL的设计理念：
* 所有模块都实现统一接口：`Runnable`
* 任意模块之间都可以`.pipe()`链接组合
* 逻辑更清晰、组合更自由、调试也更友好

快速上手
```bash
import { ChatOllama } from "@langchain/ollama";
import { PromptTemplate } from "@langchain/core/prompts";
import { StringOutputParser } from "@langchain/core/output_parsers";

# 创建模块：提示词模板、模板模块、解析器模板
# 1.创建提示词
const prompt = PromptTemplate.fromTemplate("请使用中文解释下什么：{question}");
# 2.创建模型
const model = await new ChatOllama({
  model: "llama3",
  temperature: 0.7,
});
# 3.创建一个解析器
const parser = new StringOutputParser();
# 4.将上面的三个模块连接起来：pip
const chain = prompt.pipe(model).pipe(parser);
# 5.使用chain链条 && chain.stream 也可以支持流式输出
const res = await chain.invoke({
  question: "js闭包",
});
console.log(res);
```
可以把`.pipe()`理解成模块之间的数据通道：
* `prompt`接受原始输入、并生成提示文本
* `model`根据提示生成回答
* `parser`把模型响应格式化成字符串输出

## 核心方法
* invoke 内容直接输出
* pipe 管道链接
* stream 流式输出
* batch 批量
 
### batch
该方法用于同时处理多个输入，适合批量问答、摘要等场景，返回一个**结果数组**
```bash
# 5.多条输入
const inputs = [
  { question: "闭包" },
  { question: "原型链" },
  { question: "事件循环" },
];
# 6.使用chain链条
const res = await chain.batch(inputs);
console.log(res);
```

# Runnable接口
在LCEL中，几乎所有的模块提示词模块、模型、解析器都能实现Runnable接口，可以将这些模块称为Runnable类型，这种类型的模块可以快速插入链条里面

## RunnableLambda (Lambda-拉姆达表达式)
`RunnableLambda`是LangChain.js提供的一种轻量级工具，它能把**普通函数**封装成`Runable`接口规范的示例，从而让该函数无缝参与到LCEL的链式调用与流式处理流程中

1.快速上手
```bash
import { RunnableLambda } from "@langchain/core/runnables";
const fn = (text) => {
  return text.toUpperCase();
}
const runnableFn = RunnableLambda.from(fn);
const result = await runnableFn.invoke("hello");
console.log(result);
```

2.关键词高亮插件
`闭包` --> `*&*闭包`  

```bash
import { ChatOllama } from "@langchain/ollama";
import { PromptTemplate} from '@langchain/core/prompts'
import { StringOutputParser} from '@langchain/core/output_parsers'
import {RunnableLambda} from '@langchain/core/runnables'

# 1. 创建模板
const pt = PromptTemplate.fromTemplate("请使用中文解释：{topic}");

# 2. 创建模型
const model = new ChatOllama({ model: "llama3", stream: true,temperature: 0.7 });

# 3. 创建输出解析器
const parser = new StringOutputParser();

# 4. 创建链
const chain =pt.pipe(model).pipe(parser);

# 5.创建一个简单的插件
const fn = text => text.replace(/闭包/g, '*&*闭包');
const highlight = RunnableLambda.from(fn);
# 重点是用思路，，但是这边只能用invoke 不能是用流式
const result = await chain.pipe(highlight).invoke({topic: '闭包 '});
console.log(result);
```
更多场景：
* 插入日志收集模块
* 插入翻译模块（调用外部API）
* 插入开关：判断某个条件是否中断执行
* 格式调整、结构清洗、敏感词过滤

`Pipe()`方法可以接受三种类型
* Runnable实例：这是最常用的，也是最推荐的
* 普通函数：LCEL内部会自动化`RunnableLambda.from(fn)`包装成一个`Runnable`.
* 对象：将上游的输入（或结果）分别传给多个runnable，然后返回一个对象

**接收对象实例**
```bash
import { ChatOllama } from "@langchain/ollama";
import { PromptTemplate} from '@langchain/core/prompts'
import { StringOutputParser} from '@langchain/core/output_parsers'
import {RunnableLambda} from '@langchain/core/runnables'

# 2. 创建模型
const model = new ChatOllama({ model: "llama3", temperature: 0.7 });

# 3. 创建输出解析器
const parser = new StringOutputParser();

# 创建两个子链
const chain1 = PromptTemplate.fromTemplate("请用中文2-3句概括以下主题核心含义：{input}")
  .pipe(model)
  .pipe(parser);
const chain2 = PromptTemplate.fromTemplate("请用中文从以下主题提取5个关键词，以逗号隔开：{input}")
.pipe(model)
.pipe(parser);
# pipe 可以传入一个对象的模板
const chain = RunnableLambda.from((x) => x).pipe({
  summary: chain1,
  keywords: chain2,
})
const result = await chain.invoke({input: '闭包 '});
console.log(result);
```

## RunnableMap
`RunnableMap`也叫（`RunnableParallel`）,它可以让多个链条**并发执行**，并返回结构化的对象结构
`RunnableMap.from({...})`并发执行多个子链，并将他们的结果组合成一个对象返回
```bash
import { ChatOllama } from "@langchain/ollama";
import { PromptTemplate} from '@langchain/core/prompts'
import { StringOutputParser} from '@langchain/core/output_parsers'
import {RunnableMap} from '@langchain/core/runnables'
# 2. 创建模型
const model = new ChatOllama({ model: "llama3", temperature: 0.7 });

# 3. 创建输出解析器
const parser = new StringOutputParser();

# 创建两个子链
const pt1 = PromptTemplate.fromTemplate("请用中文讲一个关于{topic}的笑话")
.pipe(model)
.pipe(parser);
const pt2 = PromptTemplate.fromTemplate("请用中文从写一首关于{topic}的诗")
.pipe(model)
.pipe(parser);

const chain = RunnableMap.from({
  joke: pt1,
  poem: pt2,
})

const result = await chain.invoke({topic: '小狗 '});
console.log(result);
```
不过，它的`.stream()`并不会将多个子链条的增量输出合并成一个统一的流，因为每一个子链的`.stream()`都会返回独立的`AsyncInterable<string>`,无法直接将多个异步迭代器在内部串联或者合并一个持续性的输出流

## RunnableSequence
`pipe()`是逐个拼接，`RunnableSequence.from([])`则是显式声明流程结构，将多个步骤写成数组更清晰
```bash
# 1. 创建模板
const pt = PromptTemplate.fromTemplate("请使用中文解释：{topic}");
# 2. 创建模型
const model = new ChatOllama({ model: "llama3", stream: true,temperature: 0.7 });
# 3. 创建输出解析器
const parser = new StringOutputParser();
# 5.创建一个简单的插件
const fn = text => text.replace(/闭包/g, '*&*闭包');
const highlight = RunnableLambda.from(fn);
# 原pipe用法：pt.pipe(model).pipe(parser).pipe(highlight);
const chain = RunnableSequence.from([pt, model, parser,highlight])
const result = await chain.invoke({topic: '闭包 '});
console.log(result);
```

## RunnablePassthrough
`RunnablePassthrough`接收一个配置对象，该对象配置func副作用函数，用于输入做一些副作用处理，比如记录日志、写入数据库、做埋点等。
```bash
import {RunnablePassthrough} from '@langchain/core/runnables'

const logger = new RunnablePassthrough({
  func: async (input) => {
    console.log("收到输入：", input);
    # 对输入做一些副作用处理，比如记录日志、写入数据库、做埋点
  }
})

await logger.invoke({input: 'Hello, world!'});
```

`.assign`方法给上下文添加字段，类似用js**Object.assign**
```bash
const injector = RunnablePassthrough.assign({
  timestamp: async () => new Date().toDateString,
  meta: async () => ({
    region: "us-east",
    requestId: "req-456",
  }),
});
const res = await injector.invoke({ input: "Hello, world!" });
console.log(res);
{
  input: 'Hello, world!',
  timestamp: [Function: toDateString],
  meta: { region: 'us-east', requestId: 'req-456' }
}
```

实战练习：
1.打印用户输入日志
2.注入userId
3.拼接prompt
4.调用本地模型
5.解析返回结果
```bash
# 1.记录日志
const logFunc = new RunnablePassthrough({
  func: async (input) => {
    # 上报、数据操作、埋点
    console.log("用户提的问题为：", input.query);
  },
});
# 2.注入用户id
const injector = RunnablePassthrough.assign({
  userId: async (input) => input.userId,
});
# 提示词模板
const pt = PromptTemplate.fromTemplate(
  "请使用中文帮用户{userId}解答：{query}, 回答问题时以亲爱的{userId}开头",
);
# 4.模型
const model = new ChatOllama({
  model: "llama3",
  temperature: 0.7,
  stream: true,
});
# 5.解析器
const parser = new StringOutputParser();
const chain = RunnableSequence.from([logFunc, injector, pt, model, parser]);
const res = await chain.stream({
  query: "闭包",
  userId: "user-12345",
});
for await (const chunk of res) {
  process.stdout.write(chunk);
}
```

# 条件路由
所谓条件路由，就是在一条AI推理/数据处理流水线里，先依据输入内容、上下文或运行时信号做一次判别，再把请求分发到不同的子流程（链）上执行。本质上受控if/else：先“判别”，再“选择”，最后“执行”，避免“一个提示词走天下”

在LangChain.js中，常用做法有两种：
1. 用`RunnableBranch`声明式按顺序匹配分支（可视作if/else的旧范式）
2. 用`RunnableLambda`在函数里动态返回要执行的子链（官方更推荐）

## RunnableBranch
基础语法
RunnableBranch是一个类，因此需要实例化，
```bash
# branches:对应类型为Branch<Runinput, Runoutput>[],其Runinput是条件，Runoutput是被选中的子链
# default 默认链条，没有命中执行
new RunnableBranch({branches, default})
```

案例：
```bash
const model = new ChatOllama({
  model: "llama3",
  temperature: 0.7,
});
const parser = new StringOutputParser();
const physicsChain = ChatPromptTemplate.fromTemplate(
  `你是一位物理学家，擅长使用中文回答物理相关问题，当你不知道问题的答案时，你就回答不知道。
  具体问题如下：
  {input}`,
)
  .pipe(model)
  .pipe(parser); # 物理链
const mathChain = ChatPromptTemplate.fromTemplate(
  `你是一位数学学家，擅长使用中文回答数学相关问题，当你不知道问题的答案时，你就回答不知道。
  具体问题如下：
  {input}`,
)
  .pipe(model)
  .pipe(parser); # 数学链
const otherChain = ChatPromptTemplate.fromTemplate(
  `你是一个AI助手，你会使用中文回答以下问题。
  具体问题如下：
  {input}`,
)
  .pipe(model)
  .pipe(parser); # 其他链

const classifyChain = ChatPromptTemplate.fromMessages([
  [
    "system",
    `你是一个仅输出标签的分类器，
    任务：将用户问题分类为以下三类之一：数学、物理、其他。
    规则：
    - 只能输出且必须输出其中一个：数学 或 物理 或 其他
    - 不要输出任务解释、理由、引导、标点、前后缀或额外空行
    - 若不确定，输出：其他`.trim(),
  ],
  [
    "human",
    `问题：{input}
    现在输出分类（仅一个词）：`.trim(),
  ],
])
  .pipe(model)
  .pipe(parser); # 分类链

# 分派器：根据topic路由对应子链
const answerBranch = RunnableBranch.from([
  [(input) => input.topic.includes("物理"), physicsChain],
  [(input) => input.topic.includes("数学"), mathChain],
  otherChain,
]);

# 最终组合
const finalChain = RunnableSequence.from([
  RunnablePassthrough.assign({
    topic: classifyChain,
  }),
  new RunnablePassthrough({
    # 日志，可以进行打印 { input: '什么是经典力学', topic: '物理' }
    func: async (input) => {
      console.log(input);
      return input;
    },
  }),
  answerBranch,
]);

const run = async () => {
  console.log(await finalChain.invoke({ input: "什么是经典力学" }));
  console.log(await finalChain.invoke({ input: "对y = x 求导的结果是多少" }));
  console.log(await finalChain.invoke({ input: "你好，你是谁？" }));
};

run();
```
