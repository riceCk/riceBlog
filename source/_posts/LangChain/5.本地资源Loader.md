# Document对象
在LangChain中，无论你的数据来源哪里——文本文件、数据库、网页还是GitHub项目，最终都会封装成统一的数据结构`Document`对象。
好处：LangChain的后续模块（比如向量化、检索器、分片器等）不需要关心数据源、只处理`Document`即可
```bash
new Document({
  pageContent: '这是一段测试文字', # 文本内容，表示这段文档的主题内容
  metadata: { # 原数据，附加的上下文信息，如来源、页面、标题等
    source: 'abc'
  }
})
```

# 目录Loader
在实际项目中，数据通常不是孤零零存在的，而是统一放在一个文件中，有多格式文件组成（比如：`.txt`、`.pdf`、`.md`等等）。这时逐个调用对应的Loader，会非常麻烦
LangChain为我们提供一个统一的————`DirectoryLoader`,可以自动识别目录中不同类型的文件，并调用对应Loader执行加载器任务。

# Web资源Loader
`CheerioWebBaseLoader`作为抓取指定网页并解析的HTML内容，提取需要的纯文本数据。
这个Loader底层依赖[cheerio](https://cheerio.js.org/docs/intro/)，语法类型JQuery，可以方便选择HTML元素并提取内容，适用于解析静态的HTML网页
```bash
pnpm add @langchain/community cheerio
```
**快速上手示例**
```bash
import { CheerioWebBaseLoader } from "@langchain/community/document_loaders/web/cheerio";
const loader = new CheerioWebBaseLoader("https://tech.meituan.com/");
const res = await loader.load();
console.log(res);
```
可以配置`selector`,提取指定HTML标签内容。
比如只提取三级菜单标题
```bash
const loader = new CheerioWebBaseLoader("https://tech.meituan.com/", {
  selector: "h3",
});
```

# Github loader
希望大模型理解某个项目的结构和实现细节，比如：
* 根据提问问题回答组件如何使用
* 根据错误信息定位源码位置
* 辅助理解项目代码逻辑

这种场景下，直接将整个GitHub仓库作为数据源加载进去，是一种非常实用的做法。
`GithubRepoLoader`来一键抓取GitHub项目内容，并自动转成`Document`对象
```bash
# 依赖ignore包
pnpm add ignore 
```
快速上手示例
```bash
import { GithubRepoLoader } from "@langchain/community/document_loaders/web/github";
const loader = new GithubRepoLoader("https://github.com/vuejs/vue", {
  branch: "main", # 指定分支
  recursive: false, # 是否递归子目录（测试建议false）
  unknown: "warn", # 遇到未知类型的文件是否警告
  ignorePaths: ["*.md", "*.json", "yarn.lock"], # 忽略的部分文件
});
const result = await loader.load();
console.log(result);
```

# SearchAPI
在很多场景中，希望AI应用会大一些最新的问题：
* 今天有什么科技新闻
* 某个API的用法有什么变动

LangChain中提供了多个工具：
1. SearchApiLoader：背后用到的服务商为[https://www.searchapi.io](https://www.searchapi.io)
2. SerpApiLoader: 背后用到的服务器商[https://serpapi.com](https://serpapi.com)

都是第三方的抓取解析提供商,需要注册apikey

快熟上手示例
```bash
import { SerpAPILoader } from "@langchain/community/document_loaders/web/serpapi";
const apikey = '提供商apikey'
const q = '什么是Copilot?'
const loader = new SerpAPILoader({
  q,
  apiKey
})
const result = await loader.load()
console.log(result)
```
`metadata.responseType`常见类型
| responseType | 含义 | 适合用途 |
|------|----------|------|
|knowledge_fraph| 权威定义、结构化知识|实体解释、百科内容|
|organic_results| 正常网页搜索结果|扩展背景、内容召回|
|people_also_ask|相关问题列表|多轮对话生成、问题推荐|
|related_questions|延伸相关问题|扩展性回答、导航引导|
|top_stories|新闻报道|实时事件聚合、更新动态|
|videos|视频资源|多模态输出、学习材料推荐|
