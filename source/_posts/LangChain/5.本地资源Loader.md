# 📄 Document

不管数据来自文本、数据库、网页还是 GitHub，Loader 最后都收成同一种结构：`Document`。后面的切分、向量化、检索只认它，不用再关心原来是 PDF 还是网页。

```js
new Document({
  pageContent: "这是一段测试文字", // 正文
  metadata: {
    source: "abc", // 来源、页码、标题等附加信息
  },
});
```

# 文本和 PDF

```bash
pnpm add @langchain/community pdf-parse
```

```js
import { PDFLoader } from "@langchain/community/document_loaders/fs/pdf";

const loader = new PDFLoader("data/111.pdf");
const res = await loader.load();
console.log(res);
```

一页（或一块）对应一个 `Document`。`metadata.source` 是文件路径，`metadata.loc` 能回到原文位置。

# 目录 Loader

文件放在一个目录里，又有 `.txt`、`.pdf`、`.md` 混在一起时，不必一种格式写一个 Loader。`DirectoryLoader` 会按扩展名挑对应的加载器。

# 网页 Loader

`CheerioWebBaseLoader` 抓静态 HTML，抽出纯文本。选择器用的是 [cheerio](https://cheerio.js.org/docs/intro)，写法和 jQuery 很像。

```bash
pnpm add @langchain/community cheerio
```

```js
import { CheerioWebBaseLoader } from "@langchain/community/document_loaders/web/cheerio";

const loader = new CheerioWebBaseLoader("https://tech.meituan.com/");
const res = await loader.load();

// 只留三级标题
const titles = new CheerioWebBaseLoader("https://tech.meituan.com/", {
  selector: "h3",
});
```

# GitHub Loader

想让模型回答「这个组件怎么用」「这段报错在哪个文件」，可以把整个仓库加载成 `Document`。

```bash
pnpm add ignore
```

```js
import { GithubRepoLoader } from "@langchain/community/document_loaders/web/github";

const loader = new GithubRepoLoader("https://github.com/vuejs/vue", {
  branch: "main",
  recursive: false, // 试跑时先不要递归子目录
  unknown: "warn",
  ignorePaths: ["*.md", "*.json", "yarn.lock"],
});
const result = await loader.load();
```

# 搜索 API

问题依赖最新信息时（今天的新闻、某个 API 是否改了），用搜索 Loader。两家都要自己注册 API Key：

1. `SearchApiLoader`：[searchapi.io](https://www.searchapi.io)
2. `SerpAPILoader`：[serpapi.com](https://serpapi.com)

```js
import { SerpAPILoader } from "@langchain/community/document_loaders/web/serpapi";

const apiKey = "提供商的 apiKey";
const loader = new SerpAPILoader({
  q: "什么是Copilot?",
  apiKey,
});
const result = await loader.load();
```

`metadata.responseType` 常见取值：

| responseType | 含义 | 适合做什么 |
|------|----------|------|
| `knowledge_graph` | 结构化的权威定义 | 实体解释、百科 |
| `organic_results` | 普通网页结果 | 补背景、做召回 |
| `people_also_ask` | 相关问题 | 多轮追问、问题推荐 |
| `related_questions` | 延伸问题 | 把回答往外扩 |
| `top_stories` | 新闻 | 看近期事件 |
| `videos` | 视频 | 推荐学习材料 |
