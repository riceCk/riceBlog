# 提示词模板

## 快速上手
```bash
import { PromptTemplate } from "@langchain/core/prompts";

const prompt = new PromptTemplate({
  inputVariables: ["period", "user"], # 输入多变量
  template: "{{test}}Good {period}, {user}!", # 模板内容
});

const result = await prompt.format({ period: "morning", user: "Alice" });

console.log(result);
```
如果最终结果需要保留`{}`字符，如果输入`{test}`等，可以使用`{{}}`进行转义


## 静态方法
**PromptTemplate.fromTemplate()** 用来快速创建模板 
```bash
import { PromptTemplate } from "@langchain/core/prompts";

const pt = PromptTemplate.fromTemplate(
  "你是一个有一个翻译助理，请将用户的输入的内容由{input_language}直接翻译翻译成{output_language}。",
);

const res = await pt.format({
  input_language: "中文",
  output_language: "英文",
});

console.log(res);
```

## 部分填充 and 动态生成变量值
先传一部分变量，生成一部分填充模板，后续再补全，类似函数编程的**柯里化**
```bash
import { PromptTemplate } from "@langchain/core/prompts";

const languageTxt = "中文"
const pt = PromptTemplate.fromTemplate(
  "你是一个有一个翻译助理，请将用户的输入的内容由{input_language}直接翻译成{output_language}。回答用户{text}",
);

const pt2 = await pt.partial({
  input_language: languageTxt, # 可以通过变量/函数传入
});

const pt3 = await pt2.partial({
  output_language: "英文",
});

const result = await pt3.format({
  text: "以下内容翻译成英文：我爱你",
});

console.log(result);
```

## 少量样本提示词
**FewShotPromptTemplate** 方法使用
```bash
import { PromptTemplate, FewShotPromptTemplate } from "@langchain/core/prompts";

const examples = [
  {
    comment: "这个产品真不错，用的太顺手了",
    sentiment: "正面",
  },
  {
    comment: "服务态度很差，再也不会来了。",
    sentiment: "负面",
  },
  {
    comment: "质量一般，性价比不高。",
    sentiment: "中性",
  },
];

const examplePt = PromptTemplate.fromTemplate(
  "评论：{comment} -> 情感：{sentiment}",
);

const pt = new FewShotPromptTemplate({
  examples,
  examplePrompt: examplePt,
  suffix: "评论：{comment} -> 情感：{sentiment}",
  inputVariables: ["comment", "sentiment"],
});

const res = await pt.format({
  comment: "外观还行，性能一般般",
  sentiment: "中性",
});

console.log(res);
# 输出：
评论：这个产品真不错，用的太顺手了 -> 情感：正面
评论：服务态度很差，再也不会来了。 -> 情感：负面
评论：质量一般，性价比不高。 -> 情感：中性

评论：外观还行，性能一般般 -> 情感：中性
```

# 结构化提示词
信息是由于人类、ai、还是chatbot指定的system信息，这种结构化的消息输入有助于模型更好的理解对话的上下文和流程，从而生成更加准确、更自然的回应

|类名|用途|
|:---:|:----:|
|ChatPrompTemplate|构造整个多轮提示词结构|
|SystemMessagePromptTemplate| 设置系统规则/行为模式|
|HumanMessagePromptTemplate|模拟用户输入|
|AIMessagePromptTemplate|模拟模型输出（上下文中使用）|

角色的概念对LLM理解和构建整个对话流程非常重要，相同的内容由不同的role发送出来的意义是不同的。
* `system`角色的消息通常用于设置对话的上下文或指定模型采取特定的行为模式。这些消息不会直接显示在对话中，但是他们对**模型的行为有指导作用**
* `user`角色代表真实用户在对话中的发言。
* `assistant`角色的信息代表AI模型的回复

## 快速上手
```bash
import {
  SystemMessagePromptTemplate,
  HumanMessagePromptTemplate,
  ChatPromptTemplate,
} from "@langchain/core/prompts";
import { ChatOllama } from "@langchain/ollama";

function buildPrompt(sysTemplate, userTemplate) {
  const sysPt = SystemMessagePromptTemplate.fromTemplate(sysTemplate);
  const hpt = HumanMessagePromptTemplate.fromTemplate(userTemplate);
  return ChatPromptTemplate.fromMessages([sysPt, hpt]);
}

const sysTemplate =
  "你是一位中国专业导游，请使用中文向游客介绍{location}的{topic}，并提供相关的历史背景和文化信息。";
const userTemplate = "我想问：{question}，请你用中文回答我。";

const pt = buildPrompt(sysTemplate, userTemplate);

const res = await pt.formatMessages({
  location: "中国某些地区",
  topic: "茶叶文化",
  question: "请你介绍一下中国的茶叶文化",
});

console.log(res) #打印出来数据

const model = new ChatOllama({
  model: "llama3",
  stream: true,
  temperature: 0.7,
});

const stream = await model.stream(res);
for await (const chunk of stream) {
  process.stdout.write(chunk.content);
}

```
执行结果如下：
```bash
[
  SystemMessage {
    "content": "你是一位中国专业导游，请使用中文向游客介绍中国某些地区的茶叶文化，并提供相关的历史背景和文化信息。",
    "additional_kwargs": {},
    "response_metadata": {}
  },
  HumanMessage {
    "content": "我想问：请你介绍一下中国的茶叶文化，请你用中文回答我。",
    "additional_kwargs": {},
    "response_metadata": {}
  }
]

# stream 流输出解答
```
这里的Langchain.js**标准的聊天消息对象结构**，每条消息都表示一次对象中的一轮发言

|字段名|类型|含义与作用|
|:-------|:----:|:------|
|SystemMessage/HumanMessage| 类实例 | 表示消息的角色类型|
|content|string|消息正文，即这条消息说了什么|
|additional_kwargs|object|额外的模型参数（可选），如工具调用，函数定义，引用等|
|response_metadata|object|模型生成后自动附加的元信息（如token用量、日志信息等）|


## 组合多个提示词
实际工程中，常常需要根据多个变量、上下文来源，动态拼接结构复杂、逻辑清晰的Prompt,此时，如果把所有逻辑都写在一个大模板里，会让Prompt难以维护、难以复用。

这就是`PipelinePromptTemplate`的用武之地，他们允许我们将多个小的Prompt模板，按顺序组合成一个“流水线”的大模板，既能**模块化建设**，又能**复用逻辑片段**。

在`PipelinePromptTemplate`中，有两个重要组合部分：
* pipelinePrompts: 一个数组，每项都是一个小模板（Prompt）,执行后产出一个变量，供后续模板使用
* finalPrompt: 最终的主模板，应用前面生成的变量，并装成完整的Prompt

```bash
import {
  PromptTemplate,
  PipelinePromptTemplate,
} from "@langchain/core/prompts";

const getDate = () => new Date().toLocaleDateString();
# 1.创建一个主模板
const mainPt = PromptTemplate.fromTemplate(
  `你是一个智能助理，今天{date},主人的信息是{userInfo},
  请根据上下文完成以下任务：
  {todo}`,
);
# 2.创建子模板
const timePt = PromptTemplate.fromTemplate("{date}, 现在是{time}");
const filledTimePl = await timePt.partial({
  date: getDate,
});
const userPt = PromptTemplate.fromTemplate("姓名：{name}, 性别： {gender}");
const taskTol = PromptTemplate.fromTemplate(`
  我想吃{time}的{dish}。
  请再次确认我的信息：{userInfo}
  `);

# 3. 可以将子模板填充到主模板里面
const finalPt = new PipelinePromptTemplate({
  pipelinePrompts: [
    {
      name: "date",
      prompt: filledTimePl,
    },
    {
      name: "userInfo",
      prompt: userPt,
    },
    {
      name: "todo",
      prompt: taskTol,
    },
  ],
  finalPrompt: mainPt,
});

const result = await finalPt.format({
  time: "12:01",
  name: "张三",
  gender: "男",
  dish: "煎蛋",
});
console.log(result);

```

可以想象每个**pipelinePrompt**是一个工序，负责“加工”一段文本，finalPrompt则总装线，评出最终成品。
