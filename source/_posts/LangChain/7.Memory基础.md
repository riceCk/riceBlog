# 🧠 Memory

模型本身不记上一轮。多轮对话要自己把历史存下来，下一轮再塞进提示词。先看内存版 `InMemoryChatMessageHistory`，进程结束就没了。

```js
import { InMemoryChatMessageHistory } from "@langchain/core/chat_history";
import { HumanMessage, AIMessage } from "@langchain/core/messages";

const messages = new InMemoryChatMessageHistory();
await messages.addMessage(new HumanMessage("你好，我叫小明"));
await messages.addMessage(new AIMessage("你好，小明！有什么我可以帮助你的吗？"));
await messages.addMessages([
  new HumanMessage("今天天气怎么样"),
  new AIMessage("天气非常晴朗哦"),
]);
console.log(await messages.getMessages());
```

常用方法：`addMessage`、`addMessages`、`addAIMessage`、`getMessages`、`clear`。

手动接进对话：每轮把 `history` 填进 `MessagesPlaceholder`，回答结束后再把这一问一答写回去。

```js
const pt = ChatPromptTemplate.fromMessages([
  SystemMessagePromptTemplate.fromTemplate(
    "你是一个健谈的中文 AI 助手，请结合上下文，尽可能详细地用中文回答。",
  ),
  new MessagesPlaceholder("history"),
  HumanMessagePromptTemplate.fromTemplate("{input}"),
]);

const history = new InMemoryChatMessageHistory();
const chain = pt.pipe(model);

async function chatLoop() {
  while (true) {
    const input = readlineSync.question("用户：").trim();
    if (!input) continue;
    if (input === "/exit") break;
    if (input === "/clear") {
      await history.clear();
      continue;
    }

    let fullRes = "";
    const stream = await chain.stream({
      input,
      history: await history.getMessages(),
    });
    for await (const chunk of stream) {
      process.stdout.write(chunk.content);
      fullRes += chunk.content;
    }
    await history.addMessages([new HumanMessage(input), new AIMessage(fullRes)]);
  }
}
```

# 自动维护聊天记录

`RunnableWithMessageHistory` 把「取出历史、写回这一轮」包进链里。用 `sessionId` 区分不同人，每个人一份历史。

```js
const chain = pt.pipe(model).pipe(new StringOutputParser());
const store = new Map();

const withHistoryChain = new RunnableWithMessageHistory({
  runnable: chain,
  getMessageHistory: (sessionId) => {
    if (!store.get(sessionId)) {
      store.set(sessionId, new InMemoryChatMessageHistory());
    }
    return store.get(sessionId);
  },
  inputMessagesKey: "input",
  historyMessagesKey: "history",
});

const cfg = {
  configurable: { sessionId: "zhangsan" },
};

const stream = await withHistoryChain.stream({ input }, cfg);
```

`inputMessagesKey` 对上用户这句话，`historyMessagesKey` 对上模板里的占位符。清空时换一份新的历史即可：

```js
const { sessionId } = cfg.configurable;
store.set(sessionId, new InMemoryChatMessageHistory());
```

# 长程记忆

窗口里的原文会越来越长。两种收法：把旧对话收成一段摘要，或把历史放进向量库按相关度再取。这里做第一种。

摘要链温度调低，让它改写档案，不要发挥。输入是「现有摘要 + 这一轮新对话」，输出只保留长期有用的信息。

```js
const model = new ChatOllama({
  model: "llama3",
  temperature: 0.1,
});

const prompt = ChatPromptTemplate.fromMessages([
  SystemMessagePromptTemplate.fromTemplate(`
你是一个滚动摘要维护器。把新对话里长期有用的信息并进已有摘要。
保留偏好、背景、长期目标；去掉寒暄和一次性细节。
新旧冲突时以新的为准。只输出摘要正文，150 到 250 字。
新对话里没有长期信息时，原样输出旧摘要。
  `),
  HumanMessagePromptTemplate.fromTemplate(`
现有摘要：
{summary}

新对话内容：
{new_lines}

请输出更新后的摘要
  `),
]);

const stripNoise = (text) =>
  text
    .replace(/^(```\w*|```)+/g, "")
    .replace(/```$/g, "")
    .replace(/^(更新后的摘要[:：])\s*/, "")
    .trim();

export const summaryChain = RunnableSequence.from([
  prompt,
  model,
  new StringOutputParser(),
  (str) => stripNoise(str),
]);
```

聊天链回答前先读摘要。这一轮结束后，只拿刚产生的两条消息去更新摘要，然后清掉原文历史，下一轮只靠这段摘要续上。

```js
let summary = "";
const history = new InMemoryChatMessageHistory();

const chatChain = RunnableSequence.from([
  new RunnableLambda({
    func: async ({ input }) => {
      await history.addMessage(new HumanMessage(input));
      return { input };
    },
  }),
  RunnablePassthrough.assign({
    maybe_summary_section: async () =>
      summary?.trim()
        ? `以下是之前对话的摘要，回答时保持一致：\n${summary}\n`
        : "",
  }),
  chatPrompt,
  chatModel,
  new StringOutputParser(),
]);

// 回答写回历史后：
await history.addMessage(new AIMessage(finalText));
const lastTwo = (await history.getMessages()).slice(-2);
const new_lines = lastTwo.map((m) => `${m.getType()}:${m.content}`).join("\n");
summary = await summaryChain.invoke({ summary, new_lines });
await history.clear();
```

# 持久化

内存和摘要都在进程里。要跨重启，就落到文件或数据库。自己包一个 `FileChatMessageHistory` 时注意两件事：

- 串行队列：同一次写入不要和另一次读撞在一起
- 原子替换：先写临时文件，再 `rename` 成正式文件。写到一半崩溃时，旧文件还在

```js
import fs from "fs/promises";
import path from "path";
import { BaseListChatMessageHistory } from "@langchain/core/chat_history";
import { HumanMessage, AIMessage } from "@langchain/core/messages";

export class FileChatMessageHistory extends BaseListChatMessageHistory {
  constructor(filepath) {
    super();
    this.filepath = filepath;
    this._q = Promise.resolve();
  }

  _enqueue(fn) {
    const run = () => fn();
    const p = this._q.then(run, run);
    this._q = p.catch(() => {});
    return p;
  }

  async _ensureDir() {
    await fs.mkdir(path.dirname(this.filepath), { recursive: true });
  }

  async _atomicWrite(text) {
    await this._ensureDir();
    const tmp = `${this.filepath}.tmp-${Date.now()}-${Math.random().toString(36).slice(2)}`;
    await fs.writeFile(tmp, text, "utf8");
    await fs.rename(tmp, this.filepath);
  }

  async _readRaw() {
    const txt = await fs.readFile(this.filepath, "utf-8");
    return JSON.parse(txt);
  }

  async _saveMessages(messages) {
    const row = messages.map((m) => ({
      type: m.getType(),
      content: m.content,
    }));
    await this._atomicWrite(JSON.stringify(row, null, 2));
  }

  async getMessages() {
    const row = await this._readRaw();
    return row.map((item) =>
      item.type === "human" ? new HumanMessage(item.content) : new AIMessage(item.content),
    );
  }

  async addMessage(message) {
    return this._enqueue(async () => {
      const msgs = await this.getMessages();
      msgs.push(message);
      await this._saveMessages(msgs);
    });
  }

  async addMessages(messages) {
    return this._enqueue(async () => {
      const msgs = await this.getMessages();
      msgs.push(...messages);
      await this._saveMessages(msgs);
    });
  }

  async clear() {
    return this._enqueue(async () => {
      await this._atomicWrite("[]");
    });
  }
}
```

社区包里已经有文件版，一般直接用它：

```js
import { FileSystemChatMessageHistory } from "@langchain/community/stores/message/file_system";

const withHistoryChain = new RunnableWithMessageHistory({
  runnable: chain,
  getMessageHistory: async (sessionId) =>
    new FileSystemChatMessageHistory({
      sessionId,
      storageDir: "./history",
    }),
  inputMessagesKey: "input",
  historyMessagesKey: "history",
});
```

`sessionId` 会变成目录里的一份记录。换一个人就换一个 id，历史不会串。
