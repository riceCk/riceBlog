# 🔤 解析器

模型原始返回值通常不是一段干净字符串，而是带元信息的消息对象。解析器负责把它收成你要的形状：字符串、列表、JSON，或一组指定字段。常见用途：

- 抽出 JSON、列表、对象、代码块
- 做清洗和格式化
- 给 Tool / Agent 提供结构化参数

数据在链上的顺序是固定的：输入 → 模板 → 模型 → 解析器 → 输出。谁先处理数据，谁就放在 `pipe` 的前面。

# 字符串解析器

`StringOutputParser` 只取出文本，不解析结构。

```js
const model = new ChatOllama({
  model: "llama3",
  temperature: 0.7,
});
const parser = new StringOutputParser();
const res = await model.pipe(parser).invoke(new HumanMessage("Tell me a joke"));
```

# 结构化输出解析器

`StructuredOutputParser` 事先声明字段名和含义。提示词里要带上 `getFormatInstructions()`，否则模型的回答对不上格式，解析会失败。它不支持流式输出。

```js
const parser = StructuredOutputParser.fromNamesAndDescriptions({
  answer: "用户问题的答案",
  evidence: "你回答用户问题所依据的答案",
  confidence: "问题答案的可信度评分，格式是百分数",
});

const model = new ChatOllama({
  model: "llama3",
  temperature: 0.7,
});

const pt = PromptTemplate.fromTemplate("请回答：\n{instructions} \n {question}");
const chain = pt.pipe(model).pipe(parser);
const res = await chain.invoke({
  question: "请用中文回答闭包",
  instructions: parser.getFormatInstructions(),
});
```

# 列表输出解析器

希望模型只返回一个列表时，用 `CommaSeparatedListOutputParser`。它要求模型用逗号分隔，再帮你拆成数组。

```js
import { CommaSeparatedListOutputParser } from "@langchain/core/output_parsers";
import { ChatOllama } from "@langchain/ollama";
import { PromptTemplate } from "@langchain/core/prompts";

const pt = PromptTemplate.fromTemplate(
  "{instructions} \n 列出三个{country}的著名互联网公司",
);

const model = new ChatOllama({
  model: "llama3",
  temperature: 0.7,
});

const parser = new CommaSeparatedListOutputParser();
const chain = pt.pipe(model).pipe(parser);
const res = await chain.invoke({
  country: "中国",
  instructions: parser.getFormatInstructions(),
});
console.log(res); // ["阿里巴巴", "腾讯", "百度"]
```

这一步的数据是这样走的：

1. 模板把 `{instructions}` 和「列出三个中国的著名互联网公司」拼成一段提示词
2. 模型按提示返回 `"阿里巴巴,腾讯,百度"`
3. 解析器拆成 `["阿里巴巴", "腾讯", "百度"]`

# JSON 解析器

只要合法 JSON，用 `JsonOutputParser`。它会从模型输出里把 JSON 抠出来，变成对象。

```js
const parser = new JsonOutputParser();
const pt = PromptTemplate.fromTemplate(
  "请提供以下城市的信息，并以JSON格式输出：城市：{city}",
);
const model = new ChatOllama({
  model: "llama3",
  temperature: 0.7,
});
const chain = pt.pipe(model).pipe(parser);
const res = await chain.invoke({
  city: "泰州",
});
console.log(res);
```

三种解析器各管一件事：

- `StringOutputParser`：整段文本原样拿回来。模型如果在 JSON 前后加了解释，那些字也会留在字符串里
- `JsonOutputParser`：只想要 JSON 对象，适合快速原型
- `StructuredOutputParser`：字段名和含义由你定，靠 `getFormatInstructions()` 约束模型
