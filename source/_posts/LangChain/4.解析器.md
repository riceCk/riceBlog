# 字符串解析器
默认情况下LangChain中调用的LLM返回的不是一个简单的字符串，而是一个包含大量元信息的对象。
## 解析器的作用
拿到模型的输出后，利用解析器可以帮助我们将LLM原始输出转行成结构化数据，常用语：
* 提取JSON、列表、对象、代码块
* 数据清洗与格式化
* 配合TOOl / Agent 提取指令参数

```bash
const model = new ChatOllama({
  model: "llama3",
  temperature: 0.7,
});
const parser = new StringOutputParser();
# 模型处理的数据经过插件parser，输出提示词
const res = await model.pipe(parser).invoke(new HumanMessage('Tell me a joke'));
```

# 结构化输出解析器
定义解析器：
```bash
const parser = StructuredOutputParser.fromNamesAndDescriptions({
  answer: "用户问题的答案",
  evidence: "你回答用户问题所依据的答案",
  confidence: "问题答案的可信度评分，格式是百分数",
});
``` 
使用解析器
但是正常使用的提示词，会报错，大模型答案无法解析，需要用到辅助方法：**getFormatInstructions**，不支持流式输出
```bash
const model = new ChatOllama({
  model: "llama3",
  temperature: 0.7,
});

const pt = PromptTemplate.fromTemplate(
  "请回答：\n{instructions} \n {question}",
);
const chain = await pt.pipe(model).pipe(parser);
const res = await chain.invoke({
  question: "请用中文回答闭包",
  instructions: parser.getFormatInstructions(),
});
```

# 列表输出解析器
有些场景，希望模型输出一个简单的字段串列表，比如：列出三个美国的互联网公司
```bash
['Fecebook', 'Google', 'Amzon']
```
这时候就需要`CommaSeparatedListOut`

```bash
import { CommaSeparatedListOutputParser } from "@langchain/core/output_parsers";
import { ChatOllama } from "@langchain/ollama";
import { PromptTemplate } from "@langchain/core/prompts";

const pt = PromptTemplate.fromTemplate(
  "{instructions} \n 列出三个{country} 的著名互联网公司",
);

/**
 * 完整的提示词：
 * Your response should be a list of comma separated values, eg: `foo, bar, baz`
 * 列出三个中国 的著名互联网公司
 */

const model = new ChatOllama({
  model: "llama3",
  temperature: 0.7,
});

const parser = new CommaSeparatedListOutputParser();

const chain = pt.pipe(model).pipe(parser);
const res = await chain.invoke({
  country: "中国",
  instructions: parser.getFormatInstructions(),
});
console.log(res);
```
补充一点**数据流向决定 pipe 顺序**
输入 → 模板 → 模型 → 解析 → 输出
谁先处理数据，谁就在最前面
```bash
# 步骤1：pt（模板填充）
输入：{ country: "中国", instructions: parser.getFormatInstructions(), }
       ↓
pt.pipe(model).pipe(parser)
#  pt 输出：
# Your response should be a list of comma separated values, eg: `foo, bar, baz` 
# "列出三个中国的著名互联网公司"

# 步骤2：model（调用模型）
输入："Your response should be a list of comma separated values, eg: `foo, bar, baz` \n 列出三个中国的著名互联网公司"
       ↓
pt.pipe(model).pipe(parser)
#  model 输出： "阿里巴巴,腾讯,百度"

# 步骤3：parser（解析输出）
输入："阿里巴巴,腾讯,百度" 
       ↓
pt.pipe(model).pipe(parser)
#  parser 输出： ["阿里巴巴", "腾讯", "百度"]
```

# JSON解析器
需要拿到一段合法的JSON格式输出，用到`JsonOutputParser`
```bash
const parser = new JsonOutputParser();
const pt = PromptTemplate.fromTemplate(
  "请提供以下城市的信息，并以JSON格式输出：城市：{city}",
);
const model = new ChatOllama({
  model: "llama3",
  temperature: 0.7,
});
const chain = pt.pipe(model).pipe(parser);
const res = await chain.invoke({
  city: "泰州",
});
console.log(res);
# 打印如下
{
  name: 'Taizhou',
  province: 'Jiangsu',
  city_code: '320300',
  latitude: 32.433333,
  longitude: 119.233333,
  population: 5120000,
  area: 8729.33,
  timezone: 'Asia/Shanghai'
}
```
和**StringOutputParser**的区别：
* StringOutputParser：有明确的字段结构，告诉大模型、必须按照格式来
* JsonOutputParser：只想提取JSON内容或做快速原型，只要输出JSON就行

```bash
const parser = new StringOutputParser();
const pt = PromptTemplate.fromTemplate(
  "请提供以下城市的信息，并以JSON格式输出：城市：{city}, 需要的字段有：name、country、location、population",
);
const model = new ChatOllama({
  model: "llama3",
  temperature: 0.7,
});
const chain = pt.pipe(model).pipe(parser);
const res = await chain.invoke({
  city: "泰州",
});
console.log(res);
# 打印如下
```
