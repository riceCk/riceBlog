# 🧩 面向对象编程二

## 静态字段和静态方法

**静态字段**

无论通过哪个实例修改静态字段，**所有实例看到的值都会变**——因为静态字段不属于某个实例，而属于类本身。

```java
Person ming = new Person("xiao ming", 12);
Person hong = new Person("xiao hong", 15);
ming.number = 88;
System.out.println(ming.number); // 88
System.out.println(hong.number); // 88
hong.number = 99;
System.out.println(ming.number); // 99
System.out.println(hong.number); // 99

class Person {
  public String name;
  public int age;
  public static int number;
  public Person(String name, int age) {
    this.name = name;
    this.age = age;
  }
}
```

**静态方法**

静态方法属于 class，不属于实例，因此内部无法访问 `this`，也无法访问实例字段，只能访问静态字段。

常用于工具类，例如：

- `Arrays.sort()`
- `Math.random()`

```java
public class Main {
    public static void main(String[] args) {
        Person.setNumber(99);
        System.out.println(Person.number);
    }
}

class Person {
    public static int number;

    public static void setNumber(int value) {
        number = value;
    }
}
```

**接口的静态字段**

1. 接口中的字段**默认隐式自带 `public static final`**，写不写修饰符都生效
2. 可以只写一部分修饰符，编译器自动补齐
3. 本质是**静态常量**：属于接口本身，不属于实现类实例，不可修改
4. 禁止用 `private`、`protected` 修饰接口内字段
5. 接口没有实例字段；抽象类可以有普通实例字段

```java
public interface Person {
  public static final int MALE = 1;
  public static final int FEMALE = 2;
}
// 可简写为（编译器自动补上 public static final）：
public interface Person {
  int MALE = 1;
  int FEMALE = 2;
}
```

## 包

**包作用域**

同一包（例如 `ming`）内，`Main` 可**直接调用** `Person` 的方法；方法即使不写 `public` 也能被同包访问。其他包则禁止访问非 `public` 成员。

```java
// ming/Main.java
package ming;

public class Main {
  public static void main (String[] args) {
    Person p = new Person();
    p.hello();
    Student s = new Student();
    s.world();
  }
}

// ming/Person.java
package ming; // 声明包名 ming

public class Person {
  void hello () {
    System.out.println("Hello");
  }
}

class Student extends Person {
  void world () {
    System.out.println("world");
  }
}
```

**import**

其他包要调用 `ming` 包中的类，有三种写法：

1. 直接写出完整类名

```java
public class Main {
  public static void main (String[] args) {
    ming.Person p = new ming.Person();
    p.hello();
  }
}
```

2. 用 `import`：可按类引入 `import ming.Person`，也可按包全量引入 `import ming.*`。通常不建议用 `*`，多包导入后很难分辨来源。

```java
import ming.Person;
// 也可以：
import ming.*;

public class Main {
  public static void main (String[] args) {
    Person p = new Person();
    p.hello();
  }
}
```

3. `import static`：导入某个类的静态字段和静态方法

```java
package main;

// 导入 System 类的所有静态字段和静态方法
import static java.lang.System.*;

public class Main {
  public static void main(String[] args) {
    // 相当于 System.out.println(...)
    out.println("Hello, world!");
  }
}
```

> ⚠️ 若两个 class 同名（如 `mr.jun.Arrays` 与 `java.util.Arrays`），只能 `import` 其中一个，另一个必须写完整类名。

**编译和运行**

假设目录结构如下：

```text
work
├── bin
└── src
    └── com
        └── itranswarp
            ├── sample
            │   └── Main.java
            └── world
                └── Person.java
```

`bin` 存放编译后的 class，`src` 按包结构存放源码。一次性编译：

```bash
$ javac -d ./bin src/**/*.java
```

`-d` 指定 class 输出到 `bin`，`src/**/*.java` 表示任意深度的 `.java` 文件。

> 💡 **注意：** Windows 不支持 `**` 这种递归搜索，需依次列出所有 `.java` 文件：

```bash
C:\work> javac -d bin src\com\itranswarp\sample\Main.java src\com\itranswarp\world\Person.java
```

## 作用域

**public** — 公共的

定义为 `public` 的 class、interface 可被其他任何类访问：

```java
package abc;
public class Hello {
  public void hi() {
  }
}

package xyz;
class Main {
  void foo() {
    // Main 可以访问 Hello
    Hello h = new Hello();
  }
}
```

**private** — 私人的

定义为 `private` 的 field、method 无法被其他类访问：

```java
package abc;
public class Hello {
    // 不能被其他类调用
    private void hi() {
    }
    public void hello() {
        this.hi();
    }
}
```

**protected**

作用于继承关系。`protected` 字段和方法可被子类（及子类的子类）访问：

```java
package abc;
public class Hello {
  // protected 方法
  protected void hi() {
  }
}

package xyz;
class Main extends Hello {
  void foo() {
    // 可以访问 protected 方法
    hi();
  }
}
```

**package**

包作用域：同一 package 内，可访问没有 `public`/`private` 修饰的 class，以及没有 `public`/`protected`/`private` 修饰的字段和方法。

```java
package abc;
// package 权限的类
class Hello {
  // package 权限的方法
  void hi() {}
}

package abc;
class Main {
  void foo() {
    Hello h = new Hello();
    h.hi();
  }
}
```

**final**

用 `final` 修饰 class，可阻止被继承：

```java
package abc;
// 无法被继承
public final class Hello {
  private int n = 0;
  protected void hi(int t) {
    long i = t;
  }
}
```

用 `final` 修饰 method，可阻止被子类覆写：

```java
package abc;

public class Hello {
  // 无法被覆写
  protected final void hi() {}
}
```

用 `final` 修饰 field，可阻止被重新赋值：

```java
package abc;

public class Hello {
  private final int n = 0;
  protected void hi() {
    this.n = 1; // error!
  }
}
```

## 内部类

**Inner Class**

一个类定义在另一个类内部：

```java
Outer outer = new Outer("Nested");
// 要实例化 Inner，须先创建 Outer 实例，再通过 outer.new 创建
Outer.Inner inner = outer.new Inner();
inner.hello();

class Outer {
  private String name;

  Outer(String name) {
    this.name = name;
  }

  class Inner {
    void hello() {
      System.out.println("Hello, " + Outer.this.name);
    }
  }
}
```

**Anonymous Class**

```java
Outer outer = new Outer("Nested");
outer.asyncHello();

class Outer {
  private String name;

  Outer(String name) {
    this.name = name;
  }

  void asyncHello() {
    Runnable r = new Runnable() {
      @Override
      public void run () {
        System.out.println("Hello, " + Outer.this.name);
      }
    };
    new Thread(r).start();
  }
}
```

**Static Nested Class**

与 Inner Class 类似，但用 `static` 修饰，称为静态内部类：

```java
public class Main {
  public static void main(String[] args) {
    Outer.StaticNested sn = new Outer.StaticNested();
    sn.hello();
  }
}

class Outer {
  private static String NAME = "OUTER";

  private String name;

  Outer(String name) {
    this.name = name;
  }

  static class StaticNested {
    void hello() {
      System.out.println("Hello, " + Outer.NAME);
    }
  }
}
```
