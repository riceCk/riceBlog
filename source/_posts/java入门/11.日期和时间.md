# 🕰️ 日期和时间

> 🎯 新代码用 `LocalDateTime`。`Date` 和 `Calendar` 只为看懂旧项目。月份在这两套 API 里的起点不一样，这是最容易看错的地方。

# Date 和 Calendar（旧 API）

## Date

`java.util.Date` 的取值方法和日常习惯对不齐，所以才要手动补：

- `getYear()` 返回的是「年份 − 1900」，要再加 1900
- `getMonth()` 是 0～11，1 月是 0，要再加 1
- `getDate()` 才是几号，范围 1～31，不用加 1

```java
Date date = new Date();
System.out.println(date.getYear() + 1900); // 必须加 1900
System.out.println(date.getMonth() + 1);   // 0～11，必须加 1
System.out.println(date.getDate());        // 1～31，不用加 1
System.out.println(date.toString());
System.out.println(date.toGMTString());
System.out.println(date.toLocaleString());
// 2026
// 10
// 29
// Thu Oct 29 09:44:58 CST 2026
// 29 Oct 2026 01:44:58 GMT
// 2026年10月29日 09:44:58
```

`toGMTString()`、`toLocaleString()` 已经过时。旧代码里见过就行。

**SimpleDateFormat** 按模式把 `Date` 格式化成字符串：

```java
Date date = new Date();
var sdf = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss");
System.out.println(sdf.format(date));
```

> 💡 `SimpleDateFormat` 不能在多线程里共用同一个实例。Web 请求里每个人 new 一个，或者改用下面的 `DateTimeFormatter`。

## Calendar

`Calendar.getInstance()` 拿到当前时间。年份不用再加 1900，月份仍然是 0～11，读出来要加 1。

`DAY_OF_WEEK`：1 是周日，2 是周一，一直到 7 是周六。和「周一当作一周的第一天」不是同一套数。

```java
Calendar c = Calendar.getInstance();
int y = c.get(Calendar.YEAR);
int m = 1 + c.get(Calendar.MONTH);
int d = c.get(Calendar.DAY_OF_MONTH);
int w = c.get(Calendar.DAY_OF_WEEK);
int hh = c.get(Calendar.HOUR_OF_DAY);
int mm = c.get(Calendar.MINUTE);
int ss = c.get(Calendar.SECOND);
int ms = c.get(Calendar.MILLISECOND);
System.out.println(new SimpleDateFormat("yyyy-MM-dd HH:mm:ss").format(c.getTime()));
System.out.println(y + "-" + m + "-" + d + " " + w + " " + hh + ":" + mm + ":" + ss + "." + ms);
```

`set` 之前先 `clear()`。不清的话，没被 set 到的时、分、秒还留着刚才的当前时间。月份仍然从 0 开始，所以 8 表示 9 月。

```java
import java.text.*;
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Calendar c = Calendar.getInstance();
        c.clear();
        c.set(Calendar.YEAR, 2019);
        c.set(Calendar.MONTH, 8); // 8 表示 9 月
        c.set(Calendar.DATE, 2);
        c.set(Calendar.HOUR_OF_DAY, 21);
        c.set(Calendar.MINUTE, 22);
        c.set(Calendar.SECOND, 23);
        System.out.println(new SimpleDateFormat("yyyy-MM-dd HH:mm:ss").format(c.getTime()));
        // 2019-09-02 21:22:23
    }
}
```

# LocalDateTime ☑️

新代码用这一套。它在 `java.time` 里，月份从 1 开始，11 就是 11 月，不用再减 1。

- `LocalDate`：只有日期
- `LocalTime`：只有时间
- `LocalDateTime`：日期加时间，业务里主用这个

```java
LocalDate d = LocalDate.now(); // 当前日期，例如 2026-10-29
LocalTime t = LocalTime.now(); // 当前时间，例如 10:55:14.279095

LocalDateTime dt = LocalDateTime.now(); // 2026-10-29T10:56:41.142090500
LocalDate date = dt.toLocalDate();      // 只留日期
LocalTime time = dt.toLocalTime();      // 只留时间
```

指定一个时间用 `of()`。这里的月份也是 1～12：

```java
LocalDate d2 = LocalDate.of(2019, 11, 30); // 2019-11-30
LocalTime t2 = LocalTime.of(15, 16, 17);   // 15:16:17
LocalDateTime dt2 = LocalDateTime.of(2019, 11, 30, 15, 16, 17);
LocalDateTime dt3 = LocalDateTime.of(d2, t2);
```

## DateTimeFormatter

格式化和解析都用它。`yyyy/MM/dd HH:mm:ss` 里的字母大小写有区别，`MM` 是月，`mm` 是分。

```java
import java.time.*;
import java.time.format.*;

public class Main {
    public static void main(String[] args) {
        DateTimeFormatter dtf = DateTimeFormatter.ofPattern("yyyy/MM/dd HH:mm:ss");
        System.out.println(dtf.format(LocalDateTime.now()));
        // 2026/10/29 11:01:07

        LocalDateTime dt2 = LocalDateTime.parse("2019/11/30 15:16:17", dtf);
        System.out.println(dt2);
        // 2019-11-30T15:16:17
    }
}
```

## 获取特殊日期

`withDayOfMonth`、`with(...)` 返回一个新对象，原来的日期不会被改掉。`TemporalAdjusters` 在 `java.time.temporal` 包里。

```java
import java.time.*;
import java.time.temporal.TemporalAdjusters;

// 本月第一天 00:00
LocalDateTime firstDay = LocalDate.now().withDayOfMonth(1).atStartOfDay();
System.out.println(firstDay);

// 本月最后一天
LocalDate lastDay = LocalDate.now().with(TemporalAdjusters.lastDayOfMonth());
System.out.println(lastDay);

// 下个月第一天
LocalDate nextMonthFirstDay = LocalDate.now().with(TemporalAdjusters.firstDayOfNextMonth());
System.out.println(nextMonthFirstDay);

// 本月第一个周一
LocalDate firstWeekday = LocalDate.now().with(TemporalAdjusters.firstInMonth(DayOfWeek.MONDAY));
System.out.println(firstWeekday);
```

## Duration 和 Period

`Duration` 是两个时刻之间隔了多久，精确到时分秒。`Period` 是两个日期之间隔了几个月、几天。

```java
LocalDateTime start = LocalDateTime.of(2019, 11, 19, 8, 15, 0);
LocalDateTime end = LocalDateTime.of(2020, 1, 9, 19, 25, 30);
Duration d = Duration.between(start, end);
System.out.println(d); // PT1235H10M30S → 1235 小时 10 分 30 秒

Period p = LocalDate.of(2019, 11, 19).until(LocalDate.of(2020, 1, 9));
System.out.println(p); // P1M21D → 1 个月 21 天
```

# 最佳实践

和旧代码交界时，用 `Instant` 做中间层。它是时间线上的一个瞬时点，不带时区。`ZonedDateTime` 才带时区。国内业务计算、展示，继续用 `LocalDateTime`。

## 旧 API 转新 API

```java
// Date -> Instant
Instant ins1 = new Date().toInstant();

// Calendar -> Instant -> ZonedDateTime
Calendar calendar = Calendar.getInstance();
Instant ins2 = calendar.toInstant();
ZonedDateTime zdt = ins2.atZone(calendar.getTimeZone().toZoneId());
```

## 新 API 转旧 API

`Date` 的构造参数是毫秒。`toEpochSecond()` 拿到的是秒，所以要乘 1000。

```java
// ZonedDateTime -> 毫秒
ZonedDateTime zdt = ZonedDateTime.now();
long ts = zdt.toEpochSecond() * 1000;

// 毫秒 -> Date
Date date = new Date(ts);

// 毫秒 -> Calendar
Calendar calendar = Calendar.getInstance();
calendar.clear();
calendar.setTimeZone(TimeZone.getTimeZone(zdt.getZone().getId()));
calendar.setTimeInMillis(zdt.toEpochSecond() * 1000);
```
