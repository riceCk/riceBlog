# 📁 File 对象

`File` 表示一条路径，路径可以是文件，也可以是目录。构造时可以传绝对路径，也可以传相对路径。绝对路径从盘符或根目录写起。相对路径相对于程序启动时的当前目录。

下面假设当前目录是 `C:\Docs`：

```java
// 绝对路径
File f = new File("C:\\Windows\\notepad.exe");
// 相对路径
File f1 = new File("sub\\javac");       // C:\Docs\sub\javac
File f2 = new File(".\\sub\\javac");    // 仍是 C:\Docs\sub\javac，. 表示当前目录
File f3 = new File("..\\sub\\javac");   // C:\sub\javac，.. 表示上一级
```

> 💡 Windows 的分隔符是 `\`，Java 字符串里要写成 `\\`。Linux 用 `/`。Java 在 Windows 上也认 `/`，新代码可以统一写成 `/`，少处理一层转义。

## 文件和目录

这些方法看的是**磁盘上是否真有这个路径**。路径写得对、但文件还没创建时，`isFile()` 也是 `false`。

- `isFile()`：是一个已存在的文件
- `isDirectory()`：是一个已存在的目录
- `canRead()`：可读
- `canWrite()`：可写
- `canExecute()`：可执行
- `length()`：文件字节大小。目录上这个值没有意义

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        File f1 = new File("C:\\Windows");
        File f2 = new File("C:\\Windows\\notepad.exe");
        System.out.println(f1.isDirectory());
        System.out.println(f2.isFile());
        System.out.println(f2.canRead());
        System.out.println(f2.canWrite());
        System.out.println(f2.canExecute());
        System.out.println(f2.length());
    }
}
```

## 创建和删除文件

`createNewFile()` 只在文件不存在时创建，成功返回 `true`。父目录必须已经存在，它不会顺手创建文件夹。`delete()` 删除这个文件。

```java
File file = new File("/path/to/file");
if (file.createNewFile()) {
    // 文件创建成功
    if (file.delete()) {
        // 删除文件成功
    }
}
```

## Path

`java.nio.file.Path` 是后来的路径类型，和 `File` 表示的是同一件事，拼接、转绝对路径更直接。需要旧 API 时用 `toFile()` 转回去。

```java
import java.io.*;
import java.nio.file.*;

public class Main {
    public static void main(String[] args) throws IOException {
        Path p1 = Paths.get(".", "project", "study"); // 用多段拼出路径
        System.out.println(p1);
        Path p2 = p1.toAbsolutePath(); // 转成绝对路径
        System.out.println(p2);
        Path p3 = p2.normalize(); // 去掉 . 和 ..，变成规整路径
        System.out.println(p3);
        File f = p3.toFile(); // 转回 File
        System.out.println(f);
        // 遍历的是路径的每一段（盘符、每一级目录），不是目录里的文件
        for (Path p : Paths.get("..").toAbsolutePath()) {
            System.out.println("  " + p);
        }
    }
}
```

# classpath 资源

配置、模板这类文件打进 jar 之后，不在某个固定磁盘路径上，而在 classpath 里。用 `Class.getResourceAsStream` 读，路径从 classpath 根目录算起，开头的 `/` 表示根，不要写成 `C:\...` 或 `new File("target/classes/...")`。

```java
try (InputStream input = Main.class.getResourceAsStream("/application.properties")) {
    // input 为 null 表示 classpath 里没有这个文件
}
```
