# 🗂️ Java 集合

`java.util` 里常用的是这三种：

- `List`：有序，可按下标访问，允许重复。例如按顺序放一批 `Student`
- `Set`：不允许重复。例如所有不重名的 `Student`
- `Map`：按 key 查 value。例如用 `name` 找到对应的 `Student`

# 使用 List

`ArrayList` 可以 `add`，也允许放入 `null`，相同元素可以出现多次。

```java
List<String> list = new ArrayList<>();
list.add("apple");
list.add(null);
list.add("pear");
list.add("apple");
String second = list.get(1); // null
System.out.println(second); // null
System.out.println(Arrays.toString(list.toArray())); // [apple, null, pear, apple]
System.out.println(list.size()); // 4
```

`List.of()` 得到的是不可变列表：不能 `add`，也不能传入 `null`，传入会抛 `NullPointerException`。

按下标遍历能跑，但不推荐。代码啰嗦，而且 `get(i)` 只有 `ArrayList` 是直接定位；换成 `LinkedList` 后，下标越大越慢。

```java
List<String> list = List.of("apple", "pear", "apple");
for (int i = 0; i < list.size(); i++) {
    String s = list.get(i);
    System.out.println(s);
}
```

`Iterator` 用两个方法往下走：`hasNext()` 问还有没有下一个，`next()` 取出下一个。

```java
List<String> list = List.of("apple", "pear", "apple");
for (Iterator<String> it = list.iterator(); it.hasNext(); ) {
    String s = it.next();
    System.out.println(s);
}
```

平时写 for-each 就够了。它内部就是用 `Iterator` 遍历：

```java
List<String> list = List.of("apple", "pear", "apple");
for (String s : list) {
    System.out.println(s);
}
```

## List 和 Array 转换

`toArray(T[])` 要传入一个类型匹配的数组。下面列表长度是 3，所以数组长度也写成 3。

```java
List<Integer> list = List.of(12, 34, 56);
Integer[] array = list.toArray(new Integer[3]);
for (Integer s : array) {
    System.out.println(s);
}
```

数组长度不想手写时，传入构造方法，长度由 List 决定：

```java
Number[] array = list.toArray(Integer[]::new);
```

反过来，数组变 List 用 `List.of`：

```java
Integer[] array = { 1, 2, 3 };
List<Integer> list = List.of(array);
```

# 使用 Map

`put(key, value)` 把一对键值放进 `Map`。同一个 key 再 `put` 一次，只会换掉原来的 value，不会留下两个相同的 key。

```java
public class Main {
    public static void main(String[] args) {
        Student s = new Student("Xiao Ming", 99);
        Map<String, Student> map = new HashMap<>();
        map.put("Xiao Ming", s);
        Student target = map.get("Xiao Ming");
        System.out.println(target == s); // true，拿到的是放进去的那个对象
        System.out.println(target.score); // 99
        Student another = map.get("Bob");
        System.out.println(another); // null，没有这个 key
    }
}

class Student {
    public String name;
    public int score;
    public Student(String name, int score) {
        this.name = name;
        this.score = score;
    }
}
```

## 遍历 Map

`keySet()` 是全部 key 组成的 `Set`。`HashMap` 不保证遍历顺序，顺序由哈希决定。

MES 里的字典、编码映射可以这样选：

- 不关心顺序 → `HashMap`
- 要保持导入 / 录入的先后 → `LinkedHashMap`
- 要按编码、名称排好再展示 → `TreeMap`

```java
public class Main {
    public static void main(String[] args) {
        Map<String, Student> map = new HashMap<>();
        map.put("Xiao Ming", new Student("Xiao Ming", 99));
        map.put("Xiao Hong", new Student("Xiao Hong", 88));
        map.put("Zhang san", new Student("Zhang san", 68));
        map.put("Bob", new Student("Bob", 90));
        for (String key : map.keySet()) {
            Student s = map.get(key);
            System.out.printf("%s-%d\n", s.name, s.score);
        }
    }
}

class Student {
    public String name;
    public int score;
    public Student(String name, int score) {
        this.name = name;
        this.score = score;
    }
}
```

`entrySet()` 里每个元素都是一对 key-value。遍历时直接拿 value，不用再 `get` 一次。

```java
Map<String, Student> map = new HashMap<>();
map.put("Xiao Ming", new Student("Xiao Ming", 99));
map.put("Xiao Hong", new Student("Xiao Hong", 88));
map.put("Zhang san", new Student("Zhang san", 68));
map.put("Bob", new Student("Bob", 90));
for (Map.Entry<String, Student> entry : map.entrySet()) {
    String key = entry.getKey();
    Student student = entry.getValue();
    System.out.println(key + "-" + student.score);
}
```

# 使用 EnumMap

key 是枚举时用 `EnumMap`，比 `HashMap` 更贴这种「一周七天」的固定集合。构造时传入枚举的 `class`。

```java
import java.time.DayOfWeek;
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Map<DayOfWeek, String> map = new EnumMap<>(DayOfWeek.class);
        map.put(DayOfWeek.MONDAY, "星期一");
        map.put(DayOfWeek.TUESDAY, "星期二");
        map.put(DayOfWeek.WEDNESDAY, "星期三");
        map.put(DayOfWeek.THURSDAY, "星期四");
        map.put(DayOfWeek.FRIDAY, "星期五");
        map.put(DayOfWeek.SATURDAY, "星期六");
        map.put(DayOfWeek.SUNDAY, "星期日");
        System.out.println(map);
        System.out.println(map.get(DayOfWeek.MONDAY));
    }
}
```

# 使用 TreeMap

`TreeMap` 按 key 的比较规则排序，规则来自 `Comparable` 或构造时传入的 `Comparator`。下面按 `name` 的字典序排，所以输出是 Bob、Lily、Tom。

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Map<Person, Integer> map = new TreeMap<>(new Comparator<Person>() {
            @Override
            public int compare(Person o1, Person o2) {
                return o1.name.compareTo(o2.name);
            }
        });
        map.put(new Person("Tom"), 4);
        map.put(new Person("Bob"), 5);
        map.put(new Person("Lily"), 1);
        for (Person key : map.keySet()) {
            System.out.println(key);
        }
        // {Person: Bob}
        // {Person: Lily}
        // {Person: Tom}
        System.out.println(map.get(new Person("Bob"))); // 5
    }
}

class Person {
    public String name;
    Person(String name) {
        this.name = name;
    }
    public String toString() {
        return "{Person: " + name + "}";
    }
}
```

# 使用 Set

和 JS 的 `Set` 一样，存的是不重复的元素。`add` 已有的元素会返回 `false`，集合里仍然只有一份。

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Set<String> set = new HashSet<>();
        System.out.println(set.add("abc")); // true
        System.out.println(set.add("xyz")); // true
        System.out.println(set.add("xyz")); // false，已存在
        System.out.println(set.contains("xyz")); // true
        System.out.println(set.contains("XYZ")); // false
        System.out.println(set.remove("hello")); // false，没有这个元素
        System.out.println(set.size()); // 2
    }
}
```

`Set` 本身不保证顺序。`SortedSet` 才保证有序：

- `HashSet` 无序，它只实现了 `Set`
- `TreeSet` 有序，它实现了 `SortedSet`

> 💡 自定义对象放进 `HashSet`，或当作 `HashMap` 的 key 时，要同时写 `equals` 和 `hashCode`。`String` 已经写好了，所以上面可以直接用。

# 使用 Iterator

`Iterator` 是统一的遍历方式，不关心这个集合内部是数组还是链表：

- 任何集合都用同一套 `hasNext` / `next`
- 调用方不用知道集合怎么存
- 集合自己返回的 `Iterator` 知道该怎么往下走

List 那一节的 for-each，就是这种写法的简写。

# 使用 Collections

## 排序

`Collections.sort` 会直接改 `List` 里元素的位置，所以必须传入可变的 `List`。`List.of` 不能排。

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        List<String> list = new ArrayList<>();
        list.add("apple");
        list.add("pear");
        list.add("orange");
        System.out.println(list); // 排序前
        Collections.sort(list);
        System.out.println(list); // 排序后
    }
}
```

## 洗牌

`Collections.shuffle` 把一个 `List` 里的元素随机打乱。

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        List<Integer> list = new ArrayList<>();
        for (int i = 0; i < 10; i++) {
            list.add(i);
        }
        System.out.println(list); // 洗牌前
        Collections.shuffle(list);
        System.out.println(list); // 洗牌后
    }
}
```

## 不可变集合

`Collections` 可以把已有集合包成只读视图，通过这个视图去 `add` 会抛 `UnsupportedOperationException`：

- `Collections.unmodifiableList(list)`
- `Collections.unmodifiableSet(set)`
- `Collections.unmodifiableMap(map)`

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        List<String> mutable = new ArrayList<>();
        mutable.add("apple");
        mutable.add("pear");
        List<String> immutable = Collections.unmodifiableList(mutable);
        immutable.add("orange"); // UnsupportedOperationException
    }
}
```

这是原列表的只读视图。改 `mutable`，`immutable` 里也能看到。要一份之后互不影响的拷贝，用 `List.copyOf(mutable)`。
