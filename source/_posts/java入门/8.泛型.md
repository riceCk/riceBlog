# 什么是泛型

```bash
public class Main{
  public static void main(String[] arg) throws Exception{
    ArrayList<String> strList = new ArrayList<String>();
  }
}

class ArrayList<T> {
    private T[] array;
    private int size;
    public void add(T e) {}
    public void remove(int index) {}
    public T get(int index) {
        return array[index];
    }
}
```
