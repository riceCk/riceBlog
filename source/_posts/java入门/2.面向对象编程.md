# 面向对象基础

## class和instance

class是一种对象模版,而`instance`是对象实例,可以创建多个`instance`，每个`instance`类型相同,`public`是用来修饰字段的，它表示这个字段可以被外部访问。`private`禁止外部访问

```bash
class Person {
    public String name;
    public int age;
}

Person ming = new Person();
ming.name = 'kevin'
ming.age = 20
```

直接操作field，容易造成逻辑混乱。为了避免外部代码直接去访问field，我们可以用private修饰field，拒绝外部访问：

```bash
class Person {
  private String name;
  private int age;

  public String getName () {
    return this.name;
  }
  public void setName(String name) {
    this.name = name;
  }
  public int getAge() {
    return this.age;
  }
  public void setAge(int age) {
    if (age < 0 || age > 100) {
      throw new IllegalArgumentException("invalid age value");
    }
    this.age = age;
  }
}
Person ming = new Person();
ming.setName("Xiao Ming"); # 设置name
ming.setAge(12); # 设置age
System.out.println(ming.getName() + ", " + ming.getAge());
```

## 方法

**可变数组参数**
可变参数用`类型...`定义，可变参数相当于数组类型：

```bash
class Group {
  private String[] names;

  public void setNames(String... names) {
      this.names = names;
  }
}
Group g = new Group();
g.setNames("Xiao Ming", "Xiao Hong", "Xiao Jun"); # 传入3个String
g.setNames("Xiao Ming", "Xiao Hong"); # 传入2个String
```

**参数绑定**
基本类型参数的传递，是调用方值的复制。双方各自的后续修改，互不影响。

```bash
class Person {
  private int age;
  public int getAge() {
    return this.age;
  }
  public void setAge(int age) {
    this.age = age;
  }
}
Person p = new Person();
int n = 15;
p.setAge(n);
System.out.println(p.getAge()); 
# 15
n = 20;
System.out.println(p.getAge()); 
# 15
```

引用类型参数的传递，调用方的变量，和接收方的参数变量，指向的是同一个对象。双方任意一方对这个对象的修改，都会影响对方（因为指向同一个对象嘛）。

```bash
class Person {
  private String[] name;
  public String getName() {
      return this.name[0] + " " + this.name[1];
  }

  public void setName(String[] name) {
      this.name = name;
  }
}

Person p = new Person();
String[] fullname = new String[] { "Homer", "Simpson" };
p.setName(fullname);
System.out.println(p.getName()); 
# "Homer", "Simpson" 
fullname[0] = "Bar";
System.out.println(p.getName()); 
# "Bar", "Simpson" 
```

**构建方法**
初始化默认值使用，每个类可以多次定义`public Person`，组成多个构造方法，满足空值、单一传参，多传参等初始化实例

```bash
class Person {
  private String name = "Unamed";
  private int age = 10;
  public Person() {} # 允许初始化不赋值的情况
  public Person(String name, int age) { # 初始化赋值情况，可以两者并存
    this.name = name;
    this.age = age;
  }
  public String getName() {
    return this.name;
  }

  public int getAge() {
    return this.age;
  }
}
Person ming = new Person("小明", 12);
Person ming1 = new Person();
System.out.println(ming.getAge());
```

## 继承

**protected**
继承有个特点，就是子类无法访问父类的`private`字段或者`private`方法。为了让子类可以访问父类的字段，我们需要把`private`改为`protected`

```bash
class Person {
    protected String name;
    protected int age;
}

class Student extends Person {
    public String hello() {
        return "Hello, " + name; # OK!
    }
}

```

**super**
调用父级实例，和js异曲同工意思

```bash
class Person {
    protected String name;
    protected int age;

    public Person(String name, int age) {
      this.name = name;
      this.age = age;
    }
}

class Student extends Person {
    protected int score;

    public Student(String name, int age, int score) {
      super(name, age); # student没有声明name和age，需要super实例化person的字段
      this.score = score;
    }
}
Student s = new Student("Xiao Ming", 12, 89);
```

**向上转型**

下面实例提到一个：

- 编译：看左边引用类型（Person，检查有没有这个方法）
- 运行：看右边真实对象类型（Student，优先执行子类重写后的版本）

```bash
# 给s装Person壳子，声明看Person的方法和字段，但是运行方法得走Student中的方法；
Person s = new Student("Xiao Ming", 12, 89);
s.hello();
class Person {
  protected String name;
  protected int age;

  public Person(String name, int age) {
    this.name = name;
    this.age = age;
  }
  protected void hello () {} # 这里s用的Person壳子，所有声明的时候必须有hello
}

class Student extends Person {
  protected int score;

  public Student(String name, int age, int score) {
    super(name, age);
    this.score = score;
  }
  public void hello () { # 右侧运行是student，所有hello方法走的这边方法
    System.out.println(this.name + "," + this.age + "," + this.score);
  }
}
```

**向下转型**
和向上转型相反，如果把一个父类类型强制转型为子类类型，就是向下转型，结论：不可以

```bash
Person p1 = new Student(); # upcasting, ok
Person p2 = new Person();
Student s1 = (Student) p1; # ok
Student s2 = (Student) p2; # 报错
```

`Person`类型p1实际指向`Student`实例，`Person`类型变量`p2`实际指向`Person`实例。在向下转型的时候，把`p1`转型为`Student`会成功，因为`p1`确实指向`Student`实例，把`p2`转型为`Student`会失败，因为`p2`的实际类型是`Person`，不能把父类变为子类，因为子类功能比父类多，多的功能无法凭空变出来。
为了避免向下转型出错，Java提供了`instanceof`操作符，可以先判断一个实例究竟是不是某种类型：

```bash
Person p = new Person();
System.out.println(p instanceof Person); # true
System.out.println(p instanceof Student); # false

Student s = new Student();
System.out.println(s instanceof Person); # true
System.out.println(s instanceof Student); # true

Student n = null;
System.out.println(n instanceof Student); # false
```

从Java 14开始，判断instanceof后，可以直接转型为指定变量，避免再次强制转型。例如，对于以下代码：

```bash
Object obj = "hello";
if (obj instanceof String) {
    String s = (String) obj;
    System.out.println(s.toUpperCase());
}
# 改下成：
Object obj = "hello";
if (obj instanceof String s) {
    # 可以直接使用变量s:
    System.out.println(s.toUpperCase());
}
```

**区分继承和组合**

核心口诀：**继承 is-a（是一种），组合 has-a（拥有一个）**
本示例：学生 Student「是一种」人 Person（继承）；学生 Student「拥有」一本书 Book（组合）

```bash

Student s = new Student("kevin", 20, 92);
System.out.println(s.hasBook());

# 2. 新建一本书对象，设置书名，通过setBook替换学生持有的书
Book b = new Book();
b.setName("Java教程");

    this.age = age;

  }

  }
}
 ```

## 多态

**注：方法名相同，方法参数相同，但方法返回值不同，也是不同的方法**
下面run的父级和子级属于不同方法，加上`@Override`可以让编译器帮助检查是否进行了正确的覆写；不加校验正常执行
```bash
public class Main {
  public static void main(String[] args) {
  }
}

class Person {
  public void run() {}
}

public class Student extends Person {
  @Override # Compile error!
  public void run(String s) {}
}
```

**实战实例**

1. `main`：JVM 规定的程序入口，固定小写，是静态方法，**不是构造方法，不负责 new 对象**
2. 构造方法：名字和类名一模一样，和`new`配合，用来创建、初始化对象
3. `Income[] incomes = new Income[]{ ... }`：父类类型数组，利用多态，可以存放父类 + 所有子类实例
4. 多态核心：父类引用指向子类对象，调用被`@Override`重写的方法时，执行子类的实现
5. `Income...`可变参数，等价于`Income[]`数组，数组可以直接传入

```bash
# override
public class Main {
  public static void main(String[] args) {
    Income[] incomes = new Income[]{
      new Income(3000),
      new Salary(7500),
      new StateCouncilSpecialAllowance(15000)
    };
    System.out.println(totalTax(incomes));
  }  
  public static double totalTax(Income... incomes) {
    double total = 0;
    for (Income income : incomes) {
      total = total + income.getTax();
    }
    return total;
  }
}


class Income {
  protected double income;

  public Income(double income) {
    this.income = income;
  }

  public double getTax() {
    return income * 0.1;
  }
}

# 正常人
class Salary extends Income {
  public Salary(double income) {
    super(income);
  }
  @Override
  public double getTax() {
    if (income <= 5000) {
      return 0;
    }
    return (income - 5000) * 0.2;
  }
}

# 特殊补贴
class StateCouncilSpecialAllowance extends Income {
  public StateCouncilSpecialAllowance(double income) {
    super(income);
  }
  @Override
  public double getTax() {
    return 0;
  }
}
```

**覆写Object方法**

```bash
class Person {
    ...
    # 显示更有意义的字符串:
    @Override
    public String toString() {
        return "Person:name=" + name;
    }

    # 比较是否相等:
    @Override
    public boolean equals(Object o) {
        # 当且仅当o为Person类型:
        if (o instanceof Person) {
            Person p = (Person) o;
            # 并且name字段相同时，返回true:
            return this.name.equals(p.name);
        }
        return false;
    }

    # 计算hash:
    @Override
    public int hashCode() {
        return this.name.hashCode();
    }

```

**调用super 和 final**

- 在子类的覆写方法中，如果要调用父类的被覆写的方法，可以通过`super`来调用,
- 如果一个父类不允许子类对它的某个方法进行覆写，可以把该方法标记为`final`
- 用`final`修饰的字段在初始化后不能被修改，可以在构建方法中初始化

```bash
class Person {
  protected String name;
  # 用final修饰的字段在初始化后不能被修改
  public final int age = 10;
  # Person p = new Person(); 实例化之后修改不可以，等同于protected
  # p.name = "New Name"; // compile error!
  public Person(String name) {
    # 可以在构建方法中初始化
    this.name = name;
  }

  public String hello() {
    return "Hello," + name;
  }
  # 父类不允许子类对它的某个方法进行覆写
  public final String getName () {
    return this.name;
  }
}
class Student extends Person {
  @Overide 
  public String hello () {
    # 调用父级hello方法：
    return super.hello() + "!";
  }

  # compile error: 不允许覆写
  @Overide
  public String getName() {
  }
}
# 一个类不希望任何其他类继承自它
final class finalPerson {
  protected String name;
}
```

## 抽象类

**abstract**
把一个方法声明为`abstract`，表示它是一个抽象方法，本身没有实现任何方法语句。因为这个抽象方法本身是无法执行的

```bash
abstract class Person {
  # 抽象类，没有任何方法语句，不加abstract会报错
  # public void run() {}; 
  public abstract void run();
}
class Student extends Person {
    @Override
    public void run() { … }
}
```

如果一个`class`定义了方法，但没有具体执行代码，这个方法就是抽象方法，抽象方法用`abstract`修饰。**无法实例化一个抽象类**
```bash
Person p = new Person(); # 编译错误
```

## 接口
如果一个抽象类没有字段，所有方法全部都是抽象方法，那就是接口`interface`
```bash
interface Person {
  void run();
  String getName();
} 
```

**implements**
当一个具体的`class`去实现一个`interface`时，需要使用`implements`关键字:

```bash
class Student implements Person {
  private String name;

  public Student(String name) {
      this.name = name;
  }

  @Override
  public void run() {
      System.out.println(this.name + " run");
  }

  @Override
  public String getName() {
      return this.name;
  }
}
```

在Java中，一个类只能继承自另一个类，不能从多个类继承。但是，一个类可以实现多个interface，例如：

```bash
class Student implements Person, Hello { # 实现了两个interface
    ...
}
```

**接口的继承**

```bash
interface Hello {
  void hello();
}

interface Person extends Hello {
  void run();
  String getName();
}

class Student implements Person {
  ....
}
```

**default方法**

```bash
interface Hello {
  default void hello() {
    System.out.println("Hello world");
  };
}
```

## 静态字段和静态方法

**静态字段**
对于静态字段，无论修改哪个实例的静态字段,**所有实例的静态字段都被修改了**,原因是静态字段并不属于实例

```bash
Person ming = new Person("xiao ming", 12);
Person hong = new Person("xiao hong", 15);
ming.number = 88;
System.out.println(ming.number); # 88
System.out.println(hong.number); # 88
hong.number = 99;
System.out.println(ming.number); # 99
System.out.println(hong.number); # 99

class Person {
  public String name;
  public int age;
  public static int number;
  public Person(String name, int age) {
    this.name = name;
    this.age = age;
  }
}
```

**静态方法**
因为静态方法属于class而不属于实例，因此，静态方法内部，无法访问this变量，也无法访问实例字段，它只能访问静态字段。
静态方法经常用于工具类。例如：

- Arrays.sort()
- Math.random()

```bash
public class Main {
    public static void main(String[] args) {
        Person.setNumber(99);
        System.out.println(Person.number);
    }
}

class Person {
    public static int number;

    public static void setNumber(int value) {
        number = value;
    }
}
```

**接口的静态字段**

1. 接口 `interface` 中的字段，**默认隐式自带 public static final**，写不写修饰符都生效；
2. 可以只写一部分修饰符，编译器自动补齐缺失的；
3. 本质是**静态常量**：属于接口本身，不属于实现类的实例，不可修改；
4. 禁止写 private、protected 修饰接口内字段；
5. 接口没有实例字段，抽象类可以拥有普通实例字段。

```bash
public interface Person {
  public static final int MALE = 1;
  public static final int FEMALE = 2;
}
# 实际上，因为interface的字段只能是public static final类型，所以我们可以把这些修饰符都去掉，上述代码可以简写为：
public interface Person {
  # 编译器会自动加上public static final:
  int MALE = 1;
  int FEMALE = 2;
}
```

## 包

**包作用域**
在同类型中目录-ming中,Main可以**直接调用Person的方法**，Person不需要写`public`也可以调用,反之其他包禁止访问不带`public`方法
```bash
# ming/Main.java
package ming;

public class Main {
  public static void main (String[] args) {
    Person p = new Person();
    p.hello();
    Student s = new Student();
    s.world();
  }
}

# ming/Person.java
package ming; // 申明包名ming

public class Person {
  void hello () {
    System.out.println("Hello");
  }
}

class Student extends Person {
  void world () {
    System.out.println("world");
  }
}
```

**import**
其他包需要调用**ming**包中的方法，他有三种写法：

1.第一种，直接写出完整类名

```bash
public class Main {
  public static void main (String[] args) {
    ming.Person p = new ming.Person();
    p.hello();
  }
}
```

2.第二种写法是用`import`语句,可以按模块引入**import ming.Person**,也可以按包全量引入`import ming.*`,不过通常不建议`*`引入，因为在导入了多个包后，很难看出属于哪个包。

```bash
import ming.Person;
# 写import的时候，可以使用*
imper ming.*

public class Main {
  public static void main (String[] args) {
    Person p = new Person();
    p.hello();
  }
}
```
