# 🔍 反射

运行时拿到一个类的 `Class` 对象，再顺着它查看字段、调用方法、创建实例，这套做法叫反射（Reflection）。上一章用 `getAnnotation` 读注解，走的就是这里的 `Class`、`Method`、`Field`。

业务代码里很少直接写反射。它又长又绕，主要给 Spring 这类框架用：框架事先不知道你的类长什么样，仍要能读到字段和方法。

## 拿到 Class

三种拿法：

```java
// 1. 类名.class
Class cls = String.class;

// 2. 已有实例，用 getClass()。多态时拿到的是运行时的真实类型
String s = "Hello";
Class cls2 = s.getClass();

// 3. 只知道完整类名
Class cls3 = Class.forName("java.lang.String");
```

```java
Person person = new Person();
Class<? extends Person> aClass1 = person.getClass();
System.out.println(aClass1); // com.atguigu.c_reffect.Person

Person s = new Student();
System.out.println(s.getClass()); // com.atguigu.c_reffect.Student，看右边真实类型
System.out.println(Person.class); // com.atguigu.c_reffect.Person
Class cls = Class.forName("com.atguigu.c_reffect.Person");
System.out.println(cls); // com.atguigu.c_reffect.Person
```

# 访问字段

| 方法 | 拿到什么 |
|---|---|
| `getField(name)` | 某个 **public** 字段，含父类 |
| `getFields()` | 全部 **public** 字段，含父类 |
| `getDeclaredField(name)` | 当前类**自己声明**的某个字段，含 `private`，不含父类 |
| `getDeclaredFields()` | 当前类自己声明的全部字段，不含父类 |

```java
public class Main {
    public static void main(String[] args) throws Exception {
        Class stdClass = Student.class;
        System.out.println(stdClass.getField("score"));
        // public int com.atguigu.c_reffect.Student.score
        System.out.println(stdClass.getDeclaredField("grade"));
        // private int com.atguigu.c_reffect.Student.grade
        System.out.println(stdClass.getField("name"));
        // public java.lang.String com.atguigu.c_reffect.Person.name
    }
}

class Student extends Person {
    public int score;
    private int grade;
}

class Person {
    public String name;
}
```

`grade` 是 private，只能走 `getDeclaredField`。`name` 是父类的 public 字段，用 `getField` 能拿到，`getDeclaredField("name")` 在 `Student` 上会失败。

## 读取字段

`f.get(对象)` 取出这个对象上该字段的值。字段是 `private` 时，先 `setAccessible(true)`，把访问检查放开。

```java
public class Main {
    public static void main(String[] args) throws Exception {
        Object p = new Person("xiao ming");
        Class c = p.getClass();
        Field f = c.getDeclaredField("name");
        f.setAccessible(true);
        Object value = f.get(p);
        System.out.println(value); // xiao ming
    }
}

class Person {
    private String name;

    public Person(String name) {
        this.name = name;
    }
}
```

## 写入字段

`f.set(对象, 新值)`。private 字段同样要先 `setAccessible(true)`。

```java
public class Main {
    public static void main(String[] args) throws Exception {
        Object p = new Person("xiao ming");
        Class c = p.getClass();
        Field f = c.getDeclaredField("name");
        f.setAccessible(true);
        f.set(p, "xiao hong");
        System.out.println(f.get(p)); // xiao hong
    }
}

class Person {
    private String name;

    public Person(String name) {
        this.name = name;
    }
}
```

# 调用方法

方法和字段是同一套命名：带 `Declared` 的只看当前类自己声明的，含 private；不带的只看 public，含父类。

| 方法 | 拿到什么 |
|---|---|
| `getMethod(name, 参数类型...)` | 某个 **public** 方法，含父类 |
| `getMethods()` | 全部 **public** 方法，含父类 |
| `getDeclaredMethod(name, 参数类型...)` | 当前类自己声明的某个方法，含 `private` |
| `getDeclaredMethods()` | 当前类自己声明的全部方法 |

拿到 `Method` 后用 `invoke` 执行。第一个参数是「对哪个对象调用」，后面才是方法自己的参数。返回值是 `Object`，按真实类型转回来。

```java
public class Main {
    public static void main(String[] args) throws Exception {
        Student stu = new Student("kevin");
        // 参数列表用来区分重载，这里对应 getScore(String)
        Method m = Student.class.getMethod("getScore", String.class);
        // 等同于 stu.getScore("传参type参数")
        Integer result = (Integer) m.invoke(stu, "传参type参数");
        System.out.println(result); // 99
    }
}

class Student extends Person {
    public int score = 99;
    private int grade = 1;

    public Student(String name) {
        super(name);
    }

    public int getScore(String type) {
        return score;
    }
}

class Person {
    private String name;

    public Person(String name) {
        this.name = name;
    }
}
```

## 调用静态方法

静态方法不属于某个实例，`invoke` 的第一个参数传 `null`。

```java
public class Main {
    public static void main(String[] args) throws Exception {
        Method m = Person.class.getMethod("getHello");
        String s = (String) m.invoke(null);
        System.out.println(s); // Hello World
    }
}

class Person {
    private String name;

    public static String getHello() {
        return "Hello World";
    }

    public Person(String name) {
        this.name = name;
    }
}
```

## 调用非 public 方法

用 `getDeclaredMethod`，再 `setAccessible(true)`，然后 `invoke`。

```java
public class Main {
    public static void main(String[] args) throws Exception {
        Person p = new Person();
        Method m = p.getClass().getDeclaredMethod("setName", String.class);
        m.setAccessible(true);
        m.invoke(p, "Bob");
        System.out.println(p.name); // Bob
    }
}

class Person {
    public String name;

    private void setName(String name) {
        this.name = name;
    }
}
```

## 多态

`Method` 从 `Person` 上拿到，`invoke` 时传入 `Student` 实例，执行的仍是子类覆写后的 `hello`。

```java
public class Main {
    public static void main(String[] args) throws Exception {
        Method h = Person.class.getMethod("hello");
        h.invoke(new Student()); // Student:hello
    }
}

class Person {
    public void hello() {
        System.out.println("Person:hello");
    }
}

class Student extends Person {
    public void hello() {
        System.out.println("Student:hello");
    }
}
```

等同于：

```java
Person p = new Student();
p.hello();
```

# 调用构造方法

平时写 `new`，反射里改成「先拿到构造方法，再 `newInstance`」。参数类型用来区分重载，和 `getMethod` 一样。

```java
// 无参，对应 new Person()
Constructor<Person> c1 = Person.class.getConstructor();
Person p1 = c1.newInstance();

// 有参，对应 new Person("xiao ming")
Constructor<Person> c2 = Person.class.getConstructor(String.class);
Person p2 = c2.newInstance("xiao ming");
```

`Person.class.newInstance()` 是旧写法，只能调无参构造。构造方法是 private 时，换成 `getDeclaredConstructor`，再 `setAccessible(true)`。
