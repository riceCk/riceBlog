# 📦 变量和数据类型

## 基本数据类型

基本数据类型是 CPU 可以直接运算的类型。Java 定义了以下几种：

* 🔢 整数类型：`byte`(1b)，`short`(2b)，`int`(4b)，`long`(8b)
* 📐 浮点数类型：`float`(4b)，`double`(8b)
* 🔤 字符类型：`char`(2b)
* ✅ 布尔类型：`boolean`

## 整型

Java 只定义了带符号整型，最高位 bit 表示符号位（`0` 正数，`1` 负数）。各类型取值范围如下：

* `byte`：-128 ~ 127
* `short`：-32768 ~ 32767
* `int`：-2147483648 ~ 2147483647
* `long`：-9223372036854775808 ~ 9223372036854775807

```java
// 定义整型
public class Main {
    public static void main(String[] args) {
        int i = 2147483647;
        int i2 = -2147483648;
        int i3 = 2_000_000_000; // 加下划线更容易识别
        int i4 = 0xff0000; // 十六进制表示的 16711680
        int i5 = 0b1000000000; // 二进制表示的 512

        long n1 = 9000000000000000000L; // long 型结尾需要加 L
        long n2 = 900; // 没加 L，此处 900 为 int，但可以赋值给 long
        int i6 = 900L; // 错误：不能把 long 赋给 int
    }
}
```

## 浮点型

浮点数就是小数。用科学计数法表示时，小数点可以「浮动」，例如 `1234.5` 可写成 `12.345×10²`，也可写成 `1.2345×10³`，因此叫浮点数。

```java
float f1 = 3.14f;
float f2 = 3.14e38f; // 科学计数法：3.14×10^38
float f3 = 1.0; // 错误：不带 f 结尾的是 double，不能赋给 float

double d = 1.79e308;
double d2 = -1.79e308;
double d3 = 4.9e-324; // 科学计数法：4.9×10^-324
```

## 布尔类型

`boolean` 只有 `true` 和 `false` 两个值，通常是关系运算的结果：

```java
boolean b1 = true;
boolean b2 = false;
boolean isGreater = 5 > 3; // true
int age = 12;
boolean isAdult = age >= 18; // false
```

## 字符类型

`char` 表示一个字符。除标准 ASCII 外，还可以表示 Unicode 字符：

```java
public class Main {
    public static void main(String[] args) {
        char a = 'A';
        char zh = '中';
        System.out.println(a);
        System.out.println(zh);
    }
}
```

## 常量

定义变量时加上 `final`，就变成常量：

```java
final double PI = 3.14; // PI 是常量
double r = 5.0;
double area = PI * r * r;
PI = 300; // compile error!
```

## var 关键字

类型名太长时，可以用 `var` 省略变量类型，由编译器根据赋值自动推断：

```java
StringBuilder sb = new StringBuilder();
// 等价写法：
var sb = new StringBuilder();
// 编译器会推断 sb 的类型为 StringBuilder
```

# 🖨️ 输入输出

| 占位符 | 说明 |
|:---:|:----:|
| `%d` | 格式化输出整数 |
| `%x` | 格式化输出十六进制整数 |
| `%f` | 格式化输出浮点数 |
| `%e` | 格式化输出科学计数法浮点数 |
| `%s` | 格式化字符串 |

```java
// 格式化输出
public class Main {
    public static void main(String[] args) {
        double d = 3.1415926;
        System.out.printf("%.2f\n", d); // 两位小数 → 3.14
        System.out.printf("%.4f\n", d); // 四位小数 → 3.1416
    }
}

public class Main {
    public static void main(String[] args) {
        int n = 12345000;
        // 注意：几个 % 占位符，就要传几个参数
        System.out.printf("n=%d, hex=%08x", n, n);
    }
}
```

## 输入

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in); // 创建 Scanner
        System.out.print("Input your name: ");
        String name = scanner.nextLine(); // 读一行字符串
        System.out.print("Input your age: ");
        int age = scanner.nextInt(); // 读整数
        System.out.printf("Hi, %s, you are %d\n", name, age);
    }
}
```

> 💡 先通过 `import java.util.Scanner` 导入类（`import` 须放在源码开头）。读字符串用 `scanner.nextLine()`，读整数用 `scanner.nextInt()`。Scanner 会自动做类型转换，不必手动转。
