# 🧩 面向对象编程一

## class 和 instance

`class` 是对象模板，`instance` 是对象实例。同一个类可以创建多个实例。`public` 修饰字段表示外部可访问，`private` 则禁止外部访问。

```java
class Person {
    public String name;
    public int age;
}

Person ming = new Person();
ming.name = "kevin";
ming.age = 20;
```

> ⚠️ 直接操作 field 容易造成逻辑混乱。用 `private` 修饰字段，拒绝外部直接访问：

```java
class Person {
  private String name;
  private int age;

  public String getName () {
    return this.name;
  }
  public void setName(String name) {
    this.name = name;
  }
  public int getAge() {
    return this.age;
  }
  public void setAge(int age) {
    if (age < 0 || age > 100) {
      throw new IllegalArgumentException("invalid age value");
    }
    this.age = age;
  }
}
Person ming = new Person();
ming.setName("Xiao Ming"); // 设置 name
ming.setAge(12); // 设置 age
System.out.println(ming.getName() + ", " + ming.getAge());
```

## 方法

**可变参数**

可变参数用 `类型...` 定义，等价于数组类型：

```java
class Group {
  private String[] names;

  public void setNames(String... names) {
      this.names = names;
  }
}
Group g = new Group();
g.setNames("Xiao Ming", "Xiao Hong", "Xiao Jun"); // 传入 3 个 String
g.setNames("Xiao Ming", "Xiao Hong"); // 传入 2 个 String
```

**参数绑定**

基本类型参数传递的是值的拷贝，双方后续修改互不影响。

```java
class Person {
  private int age;
  public int getAge() {
    return this.age;
  }
  public void setAge(int age) {
    this.age = age;
  }
}
Person p = new Person();
int n = 15;
p.setAge(n);
System.out.println(p.getAge()); // 15
n = 20;
System.out.println(p.getAge()); // 仍是 15
```

引用类型传递时，调用方变量与接收方参数指向同一对象，任意一方修改都会影响对方。

```java
class Person {
  private String[] name;
  public String getName() {
      return this.name[0] + " " + this.name[1];
  }

  public void setName(String[] name) {
      this.name = name;
  }
}

Person p = new Person();
String[] fullname = new String[] { "Homer", "Simpson" };
p.setName(fullname);
System.out.println(p.getName()); // "Homer Simpson"
fullname[0] = "Bar";
System.out.println(p.getName()); // "Bar Simpson"
```

**构造方法**

用于初始化默认值。每个类可以定义多个构造方法，覆盖空参、单参、多参等场景。

```java
class Person {
  private String name = "Unamed";
  private int age = 10;
  public Person() {} // 允许不传参初始化
  public Person(String name, int age) { // 传参初始化，可与空参并存
    this.name = name;
    this.age = age;
  }
  public String getName() {
    return this.name;
  }

  public int getAge() {
    return this.age;
  }
}
Person ming = new Person("小明", 12);
Person ming1 = new Person();
System.out.println(ming.getAge());
```

**方法重载**

```java
class Hello {
  public void hello() {
    System.out.println("Hello, world!");
  }

  public void hello(String name) {
    System.out.println("Hello, " + name + "!");
  }

  public void hello(String name, int age) {
    if (age < 18) {
      System.out.println("Hi, " + name + "!");
    } else {
      System.out.println("Hello, " + name + "!");
    }
  }
}
```

## 继承

**protected**

子类无法访问父类的 `private` 字段或方法。若希望子类可访问，把 `private` 改为 `protected`：

```java
class Person {
    protected String name;
    protected int age;
}

class Student extends Person {
    public String hello() {
        return "Hello, " + name; // OK
    }
}
```

**super**

调用父类构造/方法，和 JS 里的 `super` 异曲同工：

```java
class Person {
    protected String name;
    protected int age;

    public Person(String name, int age) {
      this.name = name;
      this.age = age;
    }
}

class Student extends Person {
    protected int score;

    public Student(String name, int age, int score) {
      super(name, age); // Student 未声明 name/age，需 super 初始化父类字段
      this.score = score;
    }
}
Student s = new Student("Xiao Ming", 12, 89);
```

**向上转型**

记住口诀：

- 🔧 **编译**：看左边引用类型（`Person`，检查有没有这个方法）
- ▶️ **运行**：看右边真实对象类型（`Student`，优先执行子类重写版本）

```java
// 给 s 装 Person 壳：声明看 Person 的方法和字段，运行走 Student 的实现
Person s = new Student("Xiao Ming", 12, 89);
s.hello();

class Person {
  protected String name;
  protected int age;

  public Person(String name, int age) {
    this.name = name;
    this.age = age;
  }
  protected void hello () {} // s 用 Person 壳，声明时必须有 hello
}

class Student extends Person {
  protected int score;

  public Student(String name, int age, int score) {
    super(name, age);
    this.score = score;
  }
  public void hello () { // 运行时是 Student，走这里
    System.out.println(this.name + "," + this.age + "," + this.score);
  }
}
```

**向下转型**

把父类类型强制转为子类类型，叫向下转型。结论：不一定成功。

```java
Person p1 = new Student(); // upcasting, ok
Person p2 = new Person();
Student s1 = (Student) p1; // ok
Student s2 = (Student) p2; // 报错
```

`p1` 实际指向 `Student`，向下转型成功；`p2` 实际是 `Person`，不能变成子类——子类功能更多，无法凭空变出来。

为避免出错，可先用 `instanceof` 判断：

```java
Person p = new Person();
System.out.println(p instanceof Person); // true
System.out.println(p instanceof Student); // false

Student s = new Student();
System.out.println(s instanceof Person); // true
System.out.println(s instanceof Student); // true

Student n = null;
System.out.println(n instanceof Student); // false
```

从 Java 14 起，`instanceof` 判断后可直接转型为指定变量，避免再次强转：

```java
Object obj = "hello";
if (obj instanceof String) {
    String s = (String) obj;
    System.out.println(s.toUpperCase());
}
// 改写成：
Object obj = "hello";
if (obj instanceof String s) {
    // 可直接使用变量 s
    System.out.println(s.toUpperCase());
}
```

**区分继承和组合**

> 📌 核心口诀：**继承 is-a（是一种），组合 has-a（拥有一个）**  
> 本示例：Student「是一种」Person（继承）；Student「拥有」一本 Book（组合）

```java
// 1. 创建学生对象，构造内部默认初始化了一本 Book，默认 name="A"
Student s = new Student("kevin", 20, 92);
System.out.println(s.hasBook());

// 2. 新建书对象，setBook 替换学生持有的书
Book b = new Book();
b.setName("Java教程");
s.setBook(b);
System.out.println(s.hasBook());

// 父类：人
class Person {
  protected String name;
  protected int age;
  public Person(String name, int age) {
    this.name = name;
    this.age = age;
  }
  public String getName () {
    return this.name;
  }
  public int getAge() {
    return this.age;
  }
}

// Student 继承 Person：Student is a Person
class Student extends Person {
  // 组合：Student has a Book
  protected Book book;
  protected int score;

  public Student (String name, int age, int score) {
    super(name, age);
    book = new Book();
    this.score = score;
  }

  public void setBook(Book book) {
    this.book = book;
  }

  public String hasBook() {
    return book.getName();
  }

  public int getScore () {
    return this.score;
  }
}

class Book {
  protected String name = "A";
  public String getName() { return this.name; }
  public void setName(String name) {
    this.name = name;
  }
}
```

## 多态

> 📝 方法名相同、参数相同，但返回值不同，也算不同方法。  
> 下面父子 `run` 属于不同方法；加上 `@Override` 可让编译器检查覆写是否正确，不加也能正常执行。

```java
public class Main {
  public static void main(String[] args) {
  }
}

class Person {
  public void run() {}
}

public class Student extends Person {
  @Override // Compile error!
  public void run(String s) {}
}
```

**实战示例**

1. `main`：JVM 规定的程序入口，固定小写，是静态方法，**不是构造方法，不负责 new 对象**
2. 构造方法：名字与类名相同，配合 `new` 创建并初始化对象
3. `Income[] incomes = new Income[]{ ... }`：父类类型数组，可存放父类 + 所有子类实例
4. 多态核心：父类引用指向子类对象，调用被 `@Override` 重写的方法时，执行子类实现
5. `Income...` 可变参数，等价于 `Income[]`，数组可直接传入

```java
public class Main {
  public static void main(String[] args) {
    Income[] incomes = new Income[]{
      new Income(3000),
      new Salary(7500),
      new StateCouncilSpecialAllowance(15000)
    };
    System.out.println(totalTax(incomes));
  }
  public static double totalTax(Income... incomes) {
    double total = 0;
    for (Income income : incomes) {
      total = total + income.getTax();
    }
    return total;
  }
}

class Income {
  protected double income;

  public Income(double income) {
    this.income = income;
  }

  public double getTax() {
    return income * 0.1;
  }
}

// 普通人薪资
class Salary extends Income {
  public Salary(double income) {
    super(income);
  }
  @Override
  public double getTax() {
    if (income <= 5000) {
      return 0;
    }
    return (income - 5000) * 0.2;
  }
}

// 特殊补贴
class StateCouncilSpecialAllowance extends Income {
  public StateCouncilSpecialAllowance(double income) {
    super(income);
  }
  @Override
  public double getTax() {
    return 0;
  }
}
```

**覆写 Object 方法**

```java
class Person {
    // ...
    // 显示更有意义的字符串
    @Override
    public String toString() {
        return "Person:name=" + name;
    }

    // 比较是否相等
    @Override
    public boolean equals(Object o) {
        if (o instanceof Person) {
            Person p = (Person) o;
            return this.name.equals(p.name);
        }
        return false;
    }

    // 计算 hash
    @Override
    public int hashCode() {
        return this.name.hashCode();
    }
}
```

**调用 super 和 final**

- 子类覆写方法中，可通过 `super` 调用父类被覆写的方法
- 父类不想让子类覆写某方法，可标记为 `final`
- `final` 修饰的字段初始化后不可改，可在构造方法中赋值

```java
class Person {
  protected String name;
  public final int age = 10;
  // Person p = new Person(); 实例化后不可改
  // p.age = 20; // compile error!
  public Person(String name) {
    this.name = name;
  }

  public String hello() {
    return "Hello," + name;
  }
  public final String getName () {
    return this.name;
  }
}
class Student extends Person {
  @Override
  public String hello () {
    return super.hello() + "!";
  }

  // compile error: 不允许覆写
  @Override
  public String getName() {
  }
}
// 一个类不希望被任何其他类继承
final class FinalPerson {
  protected String name;
}
```

## 抽象类

**abstract**

把方法声明为 `abstract`，表示抽象方法，本身没有实现。抽象方法无法直接执行。

```java
abstract class Person {
  // 抽象方法没有任何方法体，不加 abstract 会报错
  // public void run() {};
  public abstract void run();
}
class Student extends Person {
    @Override
    public void run() { /* ... */ }
}
```

如果 `class` 定义了方法却没有具体执行代码，就是抽象方法，用 `abstract` 修饰。**无法实例化抽象类**：

```java
Person p = new Person(); // 编译错误
```

## 接口

若抽象类没有字段，且所有方法都是抽象方法，那就是接口 `interface`：

```java
interface Person {
  void run();
  String getName();
}
```

**implements**

具体类实现接口时，使用 `implements`：

```java
class Student implements Person {
  private String name;

  public Student(String name) {
      this.name = name;
  }

  @Override
  public void run() {
      System.out.println(this.name + " run");
  }

  @Override
  public String getName() {
      return this.name;
  }
}
```

Java 中一个类只能继承一个类，但可以实现多个接口：

```java
class Student implements Person, Hello { // 实现两个 interface
    // ...
}
```

**接口的继承**

```java
interface Hello {
  void hello();
}

interface Person extends Hello {
  void run();
  String getName();
}

class Student implements Person {
  // ...
}
```

**default 方法**

```java
interface Hello {
  default void hello() {
    System.out.println("Hello world");
  }
}
```
