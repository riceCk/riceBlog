# 📚 Java 核心类

## 字符串和编码

### String

**字符串比较**

`s1 == s2`：编译期会把相同字面量放进常量池，引用相同则 `==` 为 `true`。比较内容请用 `equals()`。

```java
public class Main {
  public static void main(String[] args) {
    String s1 = "hello";
    String s2 = "hello";
    String s3 = "HELLO".toLowerCase();
    System.out.println(s1 == s2); // true
    System.out.println(s1 == s3); // false
    System.out.println(s1.equals(s2)); // true
  }
}
```

`String` 还提供了搜索、提取子串等方法：

```java
// 是否包含子串
"Hello".contains("ll"); // true
"Hello".indexOf("l"); // 2
"Hello".lastIndexOf("l"); // 3
"Hello".startsWith("He"); // true
"Hello".endsWith("lo"); // true
```

**提取子串：**

```java
"Hello".substring(2); // "llo"
"Hello".substring(2, 4); // "ll"
```

**去除首尾空白：**

```java
"  \tHello\r\n ".trim(); // "Hello"
// 与 trim() 不同：中文空格 \u3000 也会被 strip() 移除
"\u3000Hello\u3000".strip(); // "Hello"
" Hello ".stripLeading(); // "Hello "
" Hello ".stripTrailing(); // " Hello"
```

`isEmpty()` / `isBlank()` 判断空串与空白串：

```java
"".isEmpty();        // true，长度为 0
"  ".isEmpty();      // false，长度不为 0
"  \n".isBlank();    // true，只含空白字符
" Hello ".isBlank(); // false，含非空白字符
```

**替换子串**

按字符/字符串替换，或用正则替换：

```java
String s = "hello";
s.replace('l', 'w'); // "hewwo"
s.replace("ll", "~~"); // "he~~o"

// 正则表达式替换
String s2 = "A,,B;C ,D";
s2.replaceAll("[\\,\\;\\s]+", ","); // "A,B,C,D"
```

**分割字符串**

使用 `split()`，参数是正则。特殊符号（`.` `*` `+` 等）需要转义，例如 `\\,`：

```java
String s = "A,B,C,D,";
String[] ss = s.split(",");
System.out.println(Arrays.toString(ss));
```

**拼接字符串**

静态方法 `join()` 用指定分隔符连接数组，和 JS 的数组转字符串类似：

```java
String[] arr = {"A", "B", "C"};
String s = String.join("***", arr); // "A***B***C"
```

**格式化字符串**

`formatted()` 与 `format()` 可替换占位符生成新字符串：

- `%s`：字符串
- `%d`：整数
- `%x`：十六进制整数
- `%f`：浮点数

```java
public class Main {
  public static void main(String[] args) {
    String s = "Hi %s, your score is %d!";
    System.out.println(s.formatted("Alice", 80));
    System.out.println(String.format("Hi %s, your score is %.2f!", "Bob", 59.5));
  }
}
```

**类型转换**

```java
String.valueOf(123); // "123"
int n1 = Integer.parseInt("123"); // 123
int n2 = Integer.parseInt("ff", 16); // 按十六进制转换 → 255
```

**字符串转 boolean：**

- 仅当 `str.equals("true")` → `true`
- `"TRUE"` / `"True"` / `"1"` / `"yes"` / `"false"` / 空串 → 全部为 `false`

```java
boolean b1 = Boolean.parseBoolean("true"); // true
boolean b2 = Boolean.parseBoolean("FALSE"); // false
```

### StringBuilder

支持 `append` 拼接、`insert` 插入、`replace` 替换等，**可链式调用**。

```java
String[] fields = {"name", "position", "salary"};
String table = "employee";
String insert = buildInsertSql(table, fields);
// insert = "INSERT INTO employee (name, position, salary) VALUES (?, ?, ?)"

static String buildInsertSql(String table, String[] fields) {
  StringBuilder sb = new StringBuilder();
  sb.append("INSERT INTO ").append(table + " (");
  for (String field : fields) {
    sb.append(field + ", ");
  }
  sb.replace(sb.length() - 2, sb.length(), ") ").append("VALUES (?, ?, ?)");
  return sb.toString();
}
```

### StringJoiner

**`new StringJoiner(delimiter, prefix, suffix)`**

- `delimiter`：拼接分隔符，如 `,`
- `prefix`：开头内容
- `suffix`：结尾内容

```java
String[] names = {"Bob", "Alice", "Grace"};
var sj = new StringJoiner(",", "Hello ", "!");
for (String name : names) {
  sj.add(name);
}
System.out.println(sj.toString()); // Hello Bob,Alice,Grace!
sj.add("kevin");
System.out.println(sj.toString()); // Hello Bob,Alice,Grace,kevin!
```

不需要指定「开头」「结尾」时，可用 `String.join()`（内部也是 `StringJoiner`）：

```java
String[] names = {"Bob", "Alice", "Grace"};
var s = String.join(", ", names);
```

### 包装类型

Java 数据类型分两种：

- **基本类型：** `byte`、`short`、`int`、`long`、`boolean`、`float`、`double`、`char`
- **引用类型：** 所有 `class` 和 `interface`

引用类型可赋 `null`；基本类型不行：

```java
String s = null;
int n = null; // compile error!
```

**Integer 使用注意：**

1. `==` 比较的是**对象地址**，不是数值；比数值用 `.equals()`
2. 缓存范围：`-128 ~ 127`，此区间内 `valueOf` 复用对象；超出则新建，不能靠 `==`
3. `new Integer()` 一定创建新对象，不与缓存相等
4. 开发规范：**不要用 `new Integer`，统一用 `Integer.valueOf()`**

```java
int i = 100;
Integer n1 = new Integer(i); // 不推荐
Integer n2 = Integer.valueOf(i);
Integer n3 = Integer.valueOf("100");
System.out.println(n1 == n2); // false
System.out.println(n2 == n3); // true
System.out.println(n3 == n1); // false
```

**自动装箱 / 拆箱**

`int` → `Integer` 叫自动装箱（Auto Boxing）；`Integer` → `int` 叫自动拆箱（Auto Unboxing）：

```java
Integer n = 100; // 编译器自动 Integer.valueOf(int)
int x = n; // 编译器自动 Integer.intValue()
```

### 枚举类

**enum** 定义枚举：

```java
enum Weekday {
  SUN, MON, TUE, WED, THU, FRI, SAT;
}

Weekday day = Weekday.SUN;
if (day == Weekday.SAT || day == Weekday.SUN) {
    System.out.println("Work at home!");
} else {
    System.out.println("Work at office!");
}
```

常用方法：`name()`、`ordinal()`

```java
String s = Weekday.SUN.name(); // "SUN"
int n = Weekday.MON.ordinal(); // 1
```

**enum**本身就是`class`，可以定义`private`构建方法

```java
public class Main {
  public static void main(String[] args) {
    Weekday day = Weekday.SUN;
    if (day.dayValue == 6 || day.dayValue == 0) {
      System.out.println("Work at home!");
    } else {
      System.out.println("Work at office!");
    }
  }
}

enum Weekday {
  MON(1), TUE(2), WED(3), THU(4), FRI(5), SAT(6), SUN(0);
  public final int dayValue;
  private Weekday(int dayValue) {
    this.dayValue = dayValue;
  }
}
```

**enum**重写`toString()`方法

```java
Weekday day = Weekday.SUN;
if (day.dayValue == 6 || day.dayValue == 0) {
  System.out.println("Today is " + day + ". Work at home!");
} else {
  System.out.println("Today is " + day + ". Work at office!");
}

enum Weekday {
  MON(1, "星期一"), TUE(2, "星期二"), WED(3, "星期三"), THU(4, "星期四"), FRI(5, "星期五"), SAT(6, "星期六"), SUN(0, "星期日");

  public final int dayValue;
  private String chinese;

  private Weekday(int dayValue, String chinese) {
    this.dayValue = dayValue;
    this.chinese = chinese;
  }

  @Override
  public String toString() {
    return this.chinese;
  }
}
```

### 记录类

**record**的基本用法

```java
Point p = new Point(123, 222);
System.out.println(p.x());  // 123
System.out.println(p); # Point[x=123, y=222]

record Point(int x, int y){};
```

进阶用法**添加静态方法**，并且`public Point {...}`编写检查逻辑，限制入参规则

```java
Point p =  Point.of(12, 33);
System.out.println(p.x());
System.out.println(p);

record Point(int x, int y) {
  public static Point of() {
    return new Point(0, 0);
  }
  public static Point of(int x, int y) {
    return new Point(x, y);
  }
  public Point{
    if (x < 0 || y < 0) {
      throw new IllegalArgumentException();
    }
  }
}
```

### BigDecimal

`scale()`表示小数位数

```java
BigDecimal d1 = new BigDecimal("123.45");
BigDecimal d2 = new BigDecimal("123.4500");
BigDecimal d3 = new BigDecimal("1234500");
System.out.println(d1.scale()); // 2,两位小数
System.out.println(d2.scale()); // 4
System.out.println(d3.scale()); // 0
```

`stripTrailingZeros()`方法，可以将一个BigDecimal格式化为一个相等的，但去掉了末尾0的BigDecimal

```java
BigDecimal d1 = new BigDecimal("123.4500");
BigDecimal d2 = d1.stripTrailingZeros();
System.out.println(d1.scale()); // 4
System.out.println(d2.scale()); // 2,因为去掉了00

BigDecimal d3 = new BigDecimal("1234500");
BigDecimal d4 = d3.stripTrailingZeros();
System.out.println(d3.scale()); // 0
System.out.println(d4.scale()); // -2
// 如果一个BigDecimal的scale()返回负数，例如，-2，表示这个数是个整数，并且末尾有2个0。
```

`setScale`指定的方法进行四舍五入或者直接截断

```java
BigDecimal d1 = new BigDecimal("123.456789");
BigDecimal d2 = d1.setScale(4, RoundingMode.HALF_UP); // 四舍五入，123.4568
BigDecimal d3 = d1.setScale(4, RoundingMode.DOWN); // 直接截断，123.4567
System.out.println(d2);
System.out.println(d3);
```
